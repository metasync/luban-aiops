Each product ships its own `pyproject.toml` with `uv_build` backend and a `Makefile`; deployment is via `shared/platform-ops/gitops/dev-k8s` overlays that create an `incidents` database idempotently and deploy Deployment/Service/ConfigMap/Secret behind the platform gateway. An end-to-end smoke script `shared/platform-ops/e2e/incident-demo.sh` asserts webhook intake, query visibility, and resolved-payload semantics after `make deploy`.
