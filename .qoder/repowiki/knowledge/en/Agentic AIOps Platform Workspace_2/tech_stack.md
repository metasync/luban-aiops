Python FastAPI services packaged with `uv` and `pyproject.toml`, containerized via per-product `Dockerfile`s using a shared `base-uv` image; Kubernetes deployment through Kustomize overlays under `shared/platform-ops/gitops`; OpenTelemetry metrics and OTLP telemetry gated by `OTEL_ENABLED`; JWT signing with RSA-256 and JWKS-based verification between `identity-broker` and gateways; JSON Schema contracts in `shared/shared-contracts/schemas` enforce cross-service wire formats.
