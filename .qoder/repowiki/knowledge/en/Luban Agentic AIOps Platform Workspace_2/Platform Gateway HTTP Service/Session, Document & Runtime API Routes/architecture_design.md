Three FastAPI `APIRouter` modules (`sessions.py`, `documents.py`, `runtime.py`) register REST endpoints under `/api/v1/sessions*`, `/api/v1/documents*`, and `/api/v1/runtime`. Each handler follows a uniform pipeline: extract `x_request_id` via `resolve_request_id`, resolve caller identity via `resolve_request_identity`, enforce authorization through `enforce_policy` (or `evaluate` for dual-gate cases), then call a function in `platform_gateway.services.gateway_service` that proxies the request to the upstream agent layer. Cross-cutting concerns are centralized: `PlatformGatewaySettings` is injected via `Depends(get_settings)`, structured logs are emitted with `log_event`, and mutating session/document operations additionally emit audit events via `build_audit_event`/`emit_audit_event` from `services.audit_emitter`. Policy actions are imported as constants from `services.policy_engine` (e.g. `ACTION_SESSION_CREATE`, `ACTION_DOCUMENTS_READ`). The routes are thin — they perform no business logic, only input wiring, authorization gating, observability, and pass-through of upstream responses.
