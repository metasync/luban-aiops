The process is started by calling `tool_gateway.main.run()`, which reads `GATEWAY_HOST` and `GATEWAY_PORT` (with Kubernetes-style `tcp://IP:PORT` port fallback) to bind uvicorn. Feature toggles such as `GATEWAY_K8S_ENABLED`, `GATEWAY_ELASTIC_ENABLED`, `GATEWAY_SKILLS_SERVICE_URL`, `GATEWAY_INCIDENTS_SERVICE_URL`, and `GATEWAY_BROWSER_ENABLED` gate connector registration at bootstrap time.
