The repository is a product-oriented multi-service workspace. Each capability lives under `products/<name>/` as an independent Python package with its own `src/<service>/`, `tests/`, `Dockerfile`, `Makefile`, and `pyproject.toml`: agent-platform (agent orchestration, session store, LLM providers), platform-gateway (portal-facing edge, token verification, policy enforcement, chat/session proxying), tool-gateway (normalized tool/connector access including Playwright browser tools), identity-broker (SSO/federation/token delegation), audit-service (durable event ingest/query), incident-service (Alertmanager intake, triage, collaboration dispatch), execution-runtime (isolated bounded workers), skills-hub (Git-based Markdown skill ingestion/indexing), and operator-portal (Ant Design X web UI). Cross-cutting assets live in `shared/shared-contracts` (JSON schemas, policy bundles, validation scripts), `shared/platform-ops` (Kustomize overlays, GitOps sync scripts, e2e demos), and `shared/base-images`. The root `Makefile` orchestrates the workspace: `make verify` runs every product test suite, renders all Kustomize overlays, validates policy bundles against schemas, evaluates scenario expectations, and enforces version lockstep between `VERSION` and per-product manifests; `make build` produces coordinated container images tagged from `VERSION` plus git SHA/dirty timestamp and writes `.images.env` consumed by the deploy overlay. Dependency direction is strictly outward from products to shared contracts and inward via HTTP/gRPC APIs — there are no cross-product Python imports. Governance is enforced through `docs/specs/` (SPEC-NNN triads of spec.md/plan.md/tasks.md) and `docs/adr/` (numbered architecture decision records), with the spec index in `docs/specs/README.md` tracking status from draft through delivered and the delivery-roadmap grouping releases.
