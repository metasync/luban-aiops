The workspace is a multi-product monorepo where each child under `products/` is an independently versioned service (agent-platform, audit-service, execution-runtime, identity-broker, incident-service, platform-gateway, skills-hub, tool-gateway) plus the non-Python operator-portal SPA. Cross-cutting wiring lives at the root: `Makefile` delegates `sync/test/lint/build/push` to per-product Makefiles, while `shared/shared-contracts/` holds the JSON schemas, policy bundles, SQL migrations, and validation scripts that every product consumes as its inter-service contract surface; `shared/platform-ops/gitops/` renders Kustomize overlays for dev/runtime profiles; `mk/` provides shared Dockerfile fragments used by all image-bearing products. The top-level `verify` target composes product tests, overlay rendering, dashboard validation, policy scenario checks, version lockstep, secret-vocabulary checks, portal build, and delegated-custody / execution-failure integration proofs into one pre-commit/pre-push gate. Documentation (`docs/specs/`, `docs/adr/`, `docs/guides/`) drives implementation via spec-driven development, with release notes in `docs/agentic-aiops-platform/release-notes/` tracking each SPEC slice.
