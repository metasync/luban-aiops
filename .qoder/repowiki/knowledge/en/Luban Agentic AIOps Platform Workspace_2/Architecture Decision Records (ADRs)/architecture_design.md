A flat directory of Markdown ADRs under `docs/adr/`, each following the shared `template.md` structure with Status/Context/Decision/Alternatives Considered/Consequences sections. The index in `README.md` enumerates all records by ID (`ADR-0001`..`ADR-0017`) and tracks status (`proposed`, `accepted`, or `superseded by ADR-NNNN`). Decisions are immutable once accepted — only status changes and supersession links are permitted. Cross-references flow from specs into this index via their status headers, and superseded records point to their replacement (e.g., ADR-0015 → ADR-0016). The scope is documentation-only: no code, build artifacts, or runtime dependencies.
