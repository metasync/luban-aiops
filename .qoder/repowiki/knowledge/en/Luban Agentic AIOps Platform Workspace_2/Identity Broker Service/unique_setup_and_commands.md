Run via the `identity-service` console script (maps to `identity_service.main:run`); build with `uv build` using the `uv_build` backend; tests run with pytest under the `[dev]` dependency group; the service expects Keycloak OIDC settings (`KEYCLOAK_BASE_URL`, `KEYCLOAK_REALM`, `OIDC_*`) and optionally a persisted RSA private key path (`IDENTITY_JWT_PRIVATE_KEY_PATH`) — if unset it generates an ephemeral in-memory key on startup.
