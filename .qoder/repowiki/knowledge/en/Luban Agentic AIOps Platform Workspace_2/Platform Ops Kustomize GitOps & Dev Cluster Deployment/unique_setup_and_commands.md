`./gitops/select-runtime-profile.sh <profile>` rewrites `dev-k8s/kustomization.yaml` to pin one LLM runtime profile while preserving the always-on `mutating-dev` and `browser-dev` profiles. `./gitops/deploy-overlay.sh <overlay-dir>` requires `IMAGE_TAG` (or an exported `*.env` state file under `dev-k8s/.images.env`) and deploys into the `dev-luban-aiops` namespace, restarting all deployments when the `platform-runtime-config` or `platform-policy` ConfigMaps change. Secret provisioning is done out-of-band via the `sync-*` scripts before deployment.
