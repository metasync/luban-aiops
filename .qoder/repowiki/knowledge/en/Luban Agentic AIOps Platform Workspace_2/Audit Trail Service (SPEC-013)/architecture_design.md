Layered FastAPI application built around a strategy-pattern store abstraction. `app.py` defines the lifespan that boots an `AuditStore` (in-memory or PostgreSQL) selected by `AUDIT_STORE_BACKEND`, starts a background `RetentionTask`, and wires HTTP middleware, Prometheus metrics, and OpenTelemetry. `api/router.py` composes five route modules (`health`, `ingest`, `query`, `summary`, `export`) under `/api/v1/audit/*`; routes are thin — they validate Pydantic schemas from `schemas/`, call services, and return responses. `services/audit_store.py` declares the `AuditStore` Protocol and provides two implementations: `InMemoryAuditStore` for dev/test and `PostgresAuditStore` over a single `audit_events` table with parameterized filters and cursor pagination; both share `summarize_events` aggregation so parity tests can assert byte-identical results. `services/ingest_auth.py` authenticates callers via static Basic credentials against `AUDIT_INGEST_CLIENTS` or Kubernetes projected workload tokens validated against the cluster OIDC issuer's JWKS. `core/config.py` centralizes all env-driven settings in frozen dataclasses parsed from `AUDIT_*` variables. `main.py` is the uvicorn entry point driven by `AuditRunSettings.from_env()`. Tests under `tests/` mirror the module layout to exercise each layer independently.
