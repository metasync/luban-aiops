`npm ci && npm run dev` inside `web-ui/app/` starts the Vite dev server with `/api` proxied to `localhost:8080` (expecting a forwarded platform-gateway there). `npm test` runs the Vitest suite. At the product root, `make build` invokes the shared `mk/image.mk` targets to produce the Docker image, which reads the repository-root `VERSION` file to inject `PLATFORM_VERSION` at build time.
