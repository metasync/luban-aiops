Single-page application built with Vite + React 19 + TypeScript, served by nginx in a multi-stage Docker image. The app root (`web-ui/app/src/App.tsx`) renders an antd Layout with a role-gated sidebar (Control / Workspace sections) and a main content area that switches between view components under `src/views/` (chat, approvals, audit, incidents, permissions, tools, skills, settings). Cross-cutting concerns are isolated: `auth/` handles OIDC login, token refresh, and session storage; `api/` exposes typed fetch clients per domain (approvals, documents, incidents, sessions, models); `stream/` implements a server-sent event decoder and transport for chat streaming; `sessions/useSessionWorkspace.ts` owns operation- and development-mode session lists shared by multiple views; `roles.ts` centralizes role constants used to gate navigation entries and feature visibility. All backend calls go through `/api/`, which nginx proxies to `platform-gateway:8000`; health endpoints are proxied separately so the Settings pane can probe them. Build-time constants (`PLATFORM_VERSION`, locked React/AntD versions) are injected via `vite.config.ts` from the repo root `VERSION` and `package-lock.json`. Tests live alongside sources under `__tests__/` and run with Vitest in jsdom.
