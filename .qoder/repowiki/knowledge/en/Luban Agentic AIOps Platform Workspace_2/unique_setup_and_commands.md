`make verify` is the forge-agnostic pre-commit/pre-push gate running all product tests, Kustomize overlay rendering, policy bundle validation, scenario evaluation, and version lockstep checks. `make build` builds coordinated images across all IMAGE_PRODUCTS and writes `shared/platform-ops/gitops/dev-k8s/.images.env` consumed by `make deploy`, which invokes the dev-k8s deploy script. Policy synchronization uses `make sync-policy` to copy the canonical bundle from `shared/shared-contracts/policies/policy-default.yaml` into each consumer location, and `make policy-diff CANDIDATE=<path>` reports per-(role,action) differences. E2E demos run via `make e2e` against a deployed cluster after port-forwarding platform-gateway:18083 and identity-service:18081. Samples are installed out-of-band via `make deploy-samples` so base overlays never reference them (per SPEC-050 R-11).
