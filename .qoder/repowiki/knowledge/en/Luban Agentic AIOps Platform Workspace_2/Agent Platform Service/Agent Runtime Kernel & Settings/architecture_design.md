Three-file leaf that forms the runtime boundary between the agent-service HTTP layer and the AgentScope framework.

- `runtime_settings.py` defines a frozen `RuntimeSettings` dataclass plus provider-specific option dataclasses (`DashScopeOptions`, `DeepSeekOptions`, `OpenAIOptions`) loaded from environment variables via `_optional_*` helpers; `from_env()` is the single configuration entry point and `__post_init__` validates all tunables (kernel tuning, middleware knobs, HITL timeout, discovery, worker, incident/skills clients, authoring-trace bounds).
- `runtime_kernel.py` exposes the `AgentKernel` class, which owns per-session agent caching (`OrderedDict` with LRU eviction), per-token toolkit caching (`_toolkits` keyed by bearer token + read-only flag), and the turn entry points `reply_text` (blocking) and `stream_events` (SSE-style async iterator). It composes an AgentScope `Agent` with dynamically built middlewares (`GatewayPermissionMiddleware`, `ToolEvidenceMiddleware`, optional `TracingMiddleware`, `ReplyBudgetControlMiddleware`), a model selected from `MODEL_CATALOG` via `_build_model`, and a toolkit assembled from gateway tools discovered at runtime or built-in task tools. Cross-cutting concerns are implemented as kernel-side hooks: prose credential redaction via `StreamingProseRedactor`, evidence frame capture and persistence through `EVIDENCE_STORE`, HITL park/resume via `CONFIRMATION_REGISTRY`/`CONFIRMATION_RECORD_STORE`, signed execution request/receipt lifecycle via `EXECUTION_RECORD_STORE` and `execution_signing`, and browser flow authority tracking through shared `FLOW_APPROVALS`/`FLOW_CONTEXTS` maps observed in `_drain_trace_queue`. A thin `native_service.py` re-exports `NativeServiceSettings`, `build_native_service_app`, and `run` from `agent_service.entrypoints.native` as the process entrypoint shim.
- Dependency direction is one-way outward: the kernel imports services, providers, stores, and tool gateways but they never import back into this module; cross-process state is communicated only through contextvars (`DELEGATED_TOKEN`, `CHAT_SESSION_ID`, `EXECUTION_REQUESTS`, `EXECUTION_AUDIT_CONTEXT`, `TOOL_EVIDENCE_SINK`).
