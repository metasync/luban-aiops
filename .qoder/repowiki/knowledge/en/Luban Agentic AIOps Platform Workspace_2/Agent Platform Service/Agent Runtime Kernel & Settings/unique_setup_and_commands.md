Configuration is entirely env-driven via `RuntimeSettings.from_env()`: `AGENTSCOPE_PROVIDER`, `AGENTSCOPE_API_KEY`, `AGENTSCOPE_MODEL_NAME`, `AGENTSCOPE_MAX_ITERS`, `AGENTSCOPE_CONTEXT_TRIGGER_RATIO`, `AGENTSCOPE_TOOL_RESULT_LIMIT`, `AGENTSCOPE_TIMEZONE`, `AGENTSCOPE_KERNEL_TRACING`, `AGENTSCOPE_REPLY_TOKEN_BUDGET`, `AGENT_HITL_CONFIRM_TIMEOUT`, `TOOL_GATEWAY_URL`, `AGENT_EXECUTION_SIGNING_KEY`, `AGENT_EXECUTION_WORKER_URL`, `AGENT_BROWSER_FLOW_APPROVIAL_TTL`, `AGENT_AUDIT_SERVICE_URL`, `AGENT_INCIDENT_SERVICE_URL`, `AGENT_SKILLS_SERVICE_URL`, and provider-specific flags such as `DASHSCOPE_THINKING_ENABLE`, `DEEPSEEK_REASONING_EFFORT`, `OPENAI_PARALLEL_TOOL_CALLS`, `LUBAN_THINKING_ENABLE`.
