Three cooperating modules form a layered secret-protection and replay pipeline. `secret_params.py` is the canonical vocabulary layer: it defines `SECRET_PARAM_SUBSTRINGS`, `OPAQUE_VALUE_FIELDS`, and `KNOWN_SAFE_FIELDS` (a fail-closed allow-list per SPEC-055 R-7) and exposes predicates (`is_secret_param`, `is_opaque_value`, `is_known_safe`, `should_mask`, `is_secret_value`) plus three redaction functions — `redact_parameters` for change-request cards, `redact_evidence_parameters` for tool_call evidence frames, and `parameterize_for_trace` which replaces credential values with `TRACE_CREDENTIAL_PLACEHOLDER` so graduated flows replay via references rather than literals. It also provides `redact_secret_query` for URL query/userinfo masking and is duplicated as a constant-only twin of the gateway's `_SECRET_QUERY_PARAMS`, enforced by `validate_secret_vocabulary.py`. `prose_redaction.py` builds on that vocabulary to mask operator and assistant chat text using four layers — pinned shapes (PEM/JWT/Bearer-Basic/AKIA from `skill_draft.REDACTION_VALUE_PATTERNS`), URL query masking, `key=value` pairs, and a heuristic literal detector — with separate paths for user text (`redact_user_text`, all four layers) and assistant text (`redact_assistant_text`, narrower). A `StreamingProseRedactor` class holds back buffer tails at delta boundaries to avoid splitting URLs, harvested literals, or pinned shapes, bounded by `SHAPE_HOLD_MAX_CHARS` and `URL_SCHEME_MAX_CHARS`. `authoring_trace.py` stores the resulting parameterized steps behind an `AuthoringTraceStore` Protocol with two implementations: `InMemoryAuthoringTraceStore` (dev/CI) and `PostgresAuthoringTraceStore` (production), sharing the same schema (`authoring_trace`, `authoring_trace_target`) and lifecycle states (`draft`, `graduated`, `discarded`). The Postgres backend uses advisory locks (`pg_advisory_xact_lock`) to serialize append/close per session, enforces per-session step caps and idle-GC via SQL, and normalizes timestamps to second-precision UTC for cross-backend parity. Dependency direction is one-way: `prose_redaction` imports constants from `secret_params`; `authoring_trace` depends on neither, keeping trace storage independent of masking logic.
