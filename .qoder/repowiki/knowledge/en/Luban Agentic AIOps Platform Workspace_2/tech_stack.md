Python services built on FastAPI with `uv` for environment/package management; containerized via Docker using a shared `base-uv` image; Kubernetes deployment driven by Kustomize overlays under `shared/platform-ops/gitops`; observability via OpenTelemetry OTLP push gated by `OTEL_ENABLED`; policy evaluation uses a YAML rule bundle (`policy-default.yaml`) with `deny > require_approval > allow` precedence; identity tokens are RSA-SHA256 JWTs verified against JWKS published by `identity-broker`.
