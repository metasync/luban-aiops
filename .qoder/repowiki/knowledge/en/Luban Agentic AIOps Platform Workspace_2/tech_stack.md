Python services built with FastAPI/Uvicorn and managed via `uv` (per-product `pyproject.toml` + `uv.lock`); container images use a shared `base-uv` image; Kubernetes deployment via Kustomize overlays; Playwright headless Chromium for browser tools; AgentScope 2.0 as the runtime kernel; RSA-256 JWT signing with JWKS for identity; Prometheus metrics and OTLP tracing via OpenTelemetry; PostgreSQL and Redis as backing stores.
