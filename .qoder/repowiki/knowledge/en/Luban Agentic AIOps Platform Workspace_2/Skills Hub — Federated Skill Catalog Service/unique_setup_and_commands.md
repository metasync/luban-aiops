Build and run via the shared Makefile fragments included from `../../mk/image.mk` and `../../mk/python.mk` (targets defined there; `make help` lists them). The package installs a `skills-hub` console script entry point (`skills_hub.main:run`). Tests use pytest under `.venv` managed by uv; `make verify` includes a `validate-secret-vocabulary` step that cross-checks credential-hole literals against shared contracts.
