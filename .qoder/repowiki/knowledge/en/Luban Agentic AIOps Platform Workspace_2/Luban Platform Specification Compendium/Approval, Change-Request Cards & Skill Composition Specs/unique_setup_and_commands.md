Delivery gates referenced by the specs include `make verify` (product suites + overlays + policy rules + version lockstep), `make sync-policy` / `make validate-policy` for the canonical policy bundle, `make policy-diff` to assert zero outcome transitions, and `npm run build` / `npm test` for the operator portal.
