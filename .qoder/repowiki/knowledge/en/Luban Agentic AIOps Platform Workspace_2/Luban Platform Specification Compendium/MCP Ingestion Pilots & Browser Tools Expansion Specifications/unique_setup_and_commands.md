Each spec follows the repository's SDD gates: `approved` authorizes implementation to begin, but commit/push, deployment, and any `VERSION` bump remain separate authorization boundaries. SPEC-067 and SPEC-069 both ship gated live-check scripts (`servicenow-check.sh`, `ansible-mcp-check.sh`) parameterized via environment variables (`LIVE_TARGET=true`, `STRICT_LIVE=true`, `REDACTION_SECRETS_FILE`) that refuse to run until real literals are supplied, keeping CI self-contained against in-cluster mocks. SPEC-050 uses `make deploy-samples` / `make undeploy-samples` to install sample skills out-of-band from the base overlay.
