Pure documentation scope — three sibling SPEC directories under `docs/specs/`, each following the same scaffold (`spec.md` + `plan.md` + `tasks.md`) and sharing the project's SDD lifecycle (draft → approved → delivered, with operator-signed approval notes and a changelog). The two MCP ingestion pilots form a paired design: SPEC-069 (Ansible) builds the generic, server-agnostic `mcp` SDK-based ingestion adapter consumed by SPEC-067 (ServiceNow), which instead ships a hand-rolled REST/Table-API native connector because its PDI lacks ServiceNow's own MCP server; both depend on the substrate in SPEC-068 (outbound execution credentials) and reuse the SPEC-007 `BaseTool`/`ToolRegistry` seam rather than extending the kernel. SPEC-050 is orthogonal: it expands the existing browser connector with nine new tools (`web.select`, `web.extract`, `web.wait_for`, `web.press_key`, `web.hover`, `web.evaluate`, `web.scroll`, `web.upload_file`, `web.switch_frame`) and reorganizes tutorial content into a top-level `samples/` directory with a `skill/` + `demo/` + `target/` layout installed via `make deploy-samples`. Dependency direction inside the module is unidirectional: SPEC-069 precedes SPEC-067; SPEC-050 has no cross-reference to either pilot.
