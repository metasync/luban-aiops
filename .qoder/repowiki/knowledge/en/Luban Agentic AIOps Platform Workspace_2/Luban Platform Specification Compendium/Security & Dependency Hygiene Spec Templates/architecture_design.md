Pure documentation scope under `docs/specs/`, organized as one directory per spec plus a shared `templates/` folder. Each spec follows the canonical three-file layout (`spec.md` for requirements + acceptance criteria + impact, `plan.md` for implementation plan, `tasks.md` for task tracking), with `templates/spec.md` providing the authoring skeleton. The two concrete specs are independent leaf artifacts: SPEC-042 covers antd deprecation migration, a vitest deprecation guard, React 19 upgrade, and backend lockfile re-lock; SPEC-062 defines a read-tier `secrets.generate_password` tool plus an extensible delivery-channel interface backed by in-memory/Redis buffers and an optional gated email channel. There is no code — these files are consumed by the spec-review workflow and referenced from `delivery-roadmap.md` and the spec index.
