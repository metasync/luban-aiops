Three sequential R5-spec slices that extend one feature surface across `products/agent-platform`, `products/platform-gateway`, and `products/operator-portal`:
- SPEC-039 establishes the substrate: a typed document store (`shift_summary` type) with draft→published lifecycle, role-based `documents:create`/`documents:read` matrix (no per-document ACLs), deterministic digest + optional LLM prose layer anchored to durable records, audit events, and the first portal Documents view; add-ons R-7/R-8 add owner session rename and session-id copy.
- SPEC-040 extends the substrate by adding a deterministic `handover` section to the digest, making prose the default (with an anchoring prompt contract requiring sentence-level references to digest sections), moving Documents from Control to Workspace in the portal nav, and adding client-side Markdown export of the full document.
- SPEC-041 is UI/readability only: an operator-facing digest reference page, tabbed structured digest rendering in the drawer, bounded scrollable panes, and a creation-time deterministic counts-only summary line surfaced in list envelopes.

Dependency direction is strictly forward: each spec references the prior slice as stable and adds additive fields to `shared/shared-contracts/schemas/operation-document.schema.json` without breaking existing consumers. The gateway remains pass-through on all three slices; agent-platform owns assembly/store/routes and the portal owns rendering/navigation changes.
