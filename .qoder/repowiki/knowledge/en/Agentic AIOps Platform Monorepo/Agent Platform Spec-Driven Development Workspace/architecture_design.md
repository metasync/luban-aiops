Each feature lives in its own `SPEC-NNN-<name>/` directory containing three sibling Markdown files (`plan.md`, `spec.md`, `tasks.md`) derived from the shared templates in `templates/`, forming a single source of truth per change. Cross-cutting concerns are split into thematic child modules (platform hardening, agent runtime, identity/trust, observability, sessions, policy/approval, portal UX, LLM model integration, skills/incidents) so that related specs evolve together while remaining independently tracked. The top-level `README.md` indexes all specs and their status, enabling cross-spec dependency tracking across the platform's lifecycle from draft to delivered.
