Four sibling spec directories under `docs/specs/` form a cohesive delivery chain for the operator portal experience. SPEC-012 defines the operator guide surface (getting-started, configuration reference, troubleshooting, tool/connector guides, architecture overview) as living state docs in `docs/guides/`. SPEC-019 adds portal transparency: a sectioned sidebar (Chat / Control / Workspace), a live role×action permission matrix endpoint (`GET /api/v1/policy/matrix`) served by platform-gateway, and read-only Tools/Skills inventory proxies. SPEC-022 delivers the backend foundation — session lifecycle API (`GET/DELETE /api/v1/sessions`, transcript retrieval), voice-readiness contract via an additive `input_modality` field with two recorded invariants (metadata-only, click-gated HITL), and an environment-scoped kustomize profile (`runtime-profiles/mutating-dev`) that opt-in enables mutating tools only in dev. SPEC-023 rebuilds the portal UI on React + Ant Design X + TypeScript behind a single platform-owned SSE adapter, migrating all existing views while preserving role-scoped visibility and the SPEC-022 deferred UI contract (Appendix A). Dependency direction is strictly forward: SPEC-022 backend contracts are consumed by SPEC-023's rebuilt UI; SPEC-019's policy matrix and inventory proxies feed SPEC-023's migrated Control/Workspace views; SPEC-012's operator guides document all four slices.
