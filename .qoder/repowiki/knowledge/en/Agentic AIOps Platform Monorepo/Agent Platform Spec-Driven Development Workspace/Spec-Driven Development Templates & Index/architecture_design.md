This module is a documentation-only specification layer with no code. It defines a three-file spec contract — `spec.md` (requirements + acceptance criteria), `plan.md` (technical approach per requirement), and `tasks.md` (executable task checklist) — stored as reusable templates under `docs/specs/templates/`. Each concrete spec lives in its own directory under `docs/specs/SPEC-NNN-<slug>/` and instantiates these templates. The root `docs/specs/README.md` acts as the process contract: it declares the three-tier documentation model (Architecture Record / Feature Specs / Living State Docs), enforces sequential numbering (`SPEC-001`, `R-1`, etc.), specifies the five allowed statuses (`draft`, `approved`, `in-progress`, `delivered`, `superseded`) and their rules, and maintains a live spec index table that serves as the single source of truth for all active and historical specs. Dependency direction is one-way: concrete specs reference these templates and the README; nothing in this module references concrete specs.
