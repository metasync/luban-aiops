Two-layer composition inside the operator portal web UI. `ChatView.tsx` is the top-level React component: it owns session list state (via an injected `SessionWorkspace`), fetches the model catalog and session transcripts, wires voice input (`useSpeechRecognition`), and renders a session sidebar, message transcript, composer with model selector, and inline confirmation/evidence panels. It delegates all streaming, turn accumulation, and HITL decision flow to the `useChatStream` hook in `stream/useChatStream.ts`, which is the single view-facing surface of the stream adapter. The hook maintains per-tab turn state (`turnsRef`), a per-session turn cache (`turnsCacheRef`), an active `AbortController`, and exposes `send`, `decide`, `setSession`, and `reseedTurns`. It opens SSE connections through `transport.openStream`/`consumeStream`, dispatches decoded frames (`delta`, `tool_call`, `tool_result`, `terminal`, `confirmation_request`, `confirmation_result`, `error`) into the current turn, and handles 404 auto-creation, 401 auth errors, and 409 race resolution for confirmations. A dedicated `reseedTurns` path (SPEC-032) authoritatively replaces both live turns and the per-session cache without aborting or moving the session pointer, used by `usePendingDecisionPoll` to keep owner-side decisions in sync. Tests in `__tests__/useChatStreamReseed.test.ts` verify the same-session re-seed semantics and the no-op behavior when reseeding a non-active session.
