Two sibling spec directories under docs/specs/ capture the design of the browser connector in tool-gateway. SPEC-049 defines the baseline: a stateful BrowserConnector backed by Playwright driving a chromium-headless-shell sidecar over CDP, exposing read-tier tools (navigate, snapshot, screenshot, fill_credential) and write-tier interaction tools (click, type) bound to skill-declared flows via an origin allowlist, named credential sets, per-flow risk_class frontmatter, a single HITL confirmation gate for mutating flows, and a deviation guard that escalates unbound interactions to per-action confirmations. SPEC-050 extends this surface with nine additional tools (select, extract, wait_for, press_key, hover, evaluate, scroll, upload_file, switch_frame), splitting them into read-tier (gate_capture) and write-tier (_WebInteractionTool) categories, and reorganizes tutorial artifacts into a self-contained samples/web-checks/password-reset layout so each sample bundles skill, demo script, target pages, credentials, and deployment wiring while referencing shared platform infrastructure from shared/platform-ops/gitops/. Both specs preserve existing contracts (ToolResult envelope, tool_invoked audit events, no new policy actions) and ride the established SPEC-020/037 confirmation bridge and SPEC-021 risk-tier admission.
