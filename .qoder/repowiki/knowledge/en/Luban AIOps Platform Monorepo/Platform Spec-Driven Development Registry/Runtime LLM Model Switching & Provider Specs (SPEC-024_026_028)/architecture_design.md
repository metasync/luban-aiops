Three sibling spec directories each define one slice of the runtime model-selection architecture and reference shared ADRs (`0002-reaffirm-agentscope-runtime-kernel`, `0003-platform-owned-agent-service-contract`). SPEC-028 adds a fourth `luban` provider adapter reusing all existing selection/pinning/discovery/audit code paths, with mandatory `LUBAN_BASE_URL`, small-model-safe defaults (thinking off), and operator hosting guides plus reference K8s manifests under `shared/platform-ops/gitops/llm-hosting/`.
