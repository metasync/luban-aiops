Three independent spec directories under `docs/specs/`, each following the same plan/spec/tasks triad that governs a single release slice. SPEC-014 defines a new `products/skills-hub` FastAPI service with federated Git/local source ingestion, a JSON-schema-governed skill envelope (`shared/shared-contracts/schemas/skill.schema.json`), deterministic keyword search, and a read-only `skills.search` tool registered in tool-gateway; it deliberately reuses existing policy, audit, redaction, and evidence-panel mechanisms so no new trust surface is added. SPEC-039 introduces a typed document substrate inside `products/agent-platform` with a draft→published lifecycle, role-based access matrix (`documents:create`, `documents:read`, `session:update`), provenance anchoring to durable stores, and the first document type `shift_summary`; Phase 1 also adds session rename and session-id copy as add-ons. SPEC-041 extends SPEC-039 with operator-facing readability: a dedicated reference guide, tabbed structured digest rendering in the portal drawer, bounded scroll panes, and a deterministic counts-only summary line computed at creation time. Dependency direction is one-way: specs reference shared contracts and existing products (tool-gateway, agent-platform, operator-portal, platform-gateway) but do not depend on each other except that SPEC-041 explicitly builds on SPEC-039's substrate.
