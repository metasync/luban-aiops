The service is a layered FastAPI application built around `src/platform_gateway/app.py`, which creates the `FastAPI` instance, installs an HTTP middleware for request logging, includes metrics/telemetry, and mounts the central router. `api/router.py` aggregates feature routers under `api/routes/` (chat, sessions, documents, tools, skills, incidents, approvals, audit, identity, auth, policy, runtime, models, health), each route file performing the standard auth → policy-enforce → delegate-token → proxy flow. Business logic lives in `services/gateway_service.py`, which wraps `httpx.AsyncClient` calls to upstream services (`agent_client`, `delegation_client`, `incident_client`, `skills_hub_client`, `tool_gateway_client`) and implements shared error posture: upstream 4xx pass through unchanged, transport/upstream 5xx map to 502. Authentication is handled by `services/token_verifier.py` (local JWT verification against JWKS) with a synthetic dev identity fallback when `require_auth` is disabled. Authorization is enforced centrally via `services/policy_engine.py` + `services/policy_matrix.py`, which load rules from the YAML bundle at `policies/policy-default.yaml` (deny-by-default, explicit deny overrides, require_approval tiers tier_1/tier_2). Cross-cutting concerns are isolated in `core/`: `config.py` defines a frozen `PlatformGatewaySettings` dataclass loaded from environment variables via `get_settings()` cached with `lru_cache`; `observability.py` provides structured event logging; `metrics.py` exposes Prometheus counters; `telemetry.py` wires OpenTelemetry; `request_context.py` resolves `x-request-id`. Schemas are declared in `schemas/api.py` using Pydantic v2. The entry point is registered as the `platform-gateway` console script in `pyproject.toml` and served via uvicorn.
