Deploy via `./gitops/deploy-overlay.sh <overlay-dir>` with `IMAGE_TAG` set (produced by `make build`); default namespace is `dev-luban-aiops`. Image tags are resolved from `.images.env` or exported variables like `AGENT_SERVICE_IMAGE`. Secret sync helpers (`sync-*-secrets.sh`) must be run before deploy to populate per-service secrets. Runtime profiles under `gitops/runtime-profiles/` are selected via `select-runtime-profile.sh` and verified with `verify-runtime-profile.sh`.
