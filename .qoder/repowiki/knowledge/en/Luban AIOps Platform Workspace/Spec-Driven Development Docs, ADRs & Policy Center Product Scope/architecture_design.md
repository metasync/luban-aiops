The module is a documentation-and-specification layer organized into four cooperating tiers. `docs/adr/` holds immutable Architecture Decision Records (numbered `NNNN-slug.md`, status-gated proposed→accepted→superseded) that capture cross-product decisions; new architectural choices are added here rather than edited in long-form docs. `docs/specs/SPEC-NNN-<slug>/` directories each own one feature spec split into three files — `spec.md` (requirements + acceptance criteria), `plan.md` (technical approach), `tasks.md` (execution checklist) — following templates under `docs/specs/templates/`; specs progress through draft/approved/in-progress/delivered/superseded statuses and form an index in `docs/specs/README.md`. `docs/agentic-aiops-platform/` contains Tier 1 long-lived architecture documents (decision matrix, reference architecture, identity design, authorization matrix, policy specification, delivery roadmap) and release notes under `release-notes/` dated by release date. `docs/guides/` provides Tier 3 living state user/operator documentation (getting started, configuration, troubleshooting, skills, HITL, etc.). `products/policy-center/README.md` defines the future standalone policy evaluation service scope, ownership, integration points, and current stub status, deferring implementation to lift `tool-gateway`'s `policy_engine.py` behind a `POST /policy/evaluate` endpoint per SPEC-004 and later approval outcomes from SPEC-030.
