Entry point is the `identity-service` console script defined in `pyproject.toml` (`identity_service.main:run`). Build uses `uv_build` backend with dependencies pinned in `uv.lock`; development deps include pytest and jsonschema for contract validation. The service reads all configuration from environment variables (e.g. `IDENTITY_JWT_PRIVATE_KEY_PATH`, `KEYCLOAK_BASE_URL`, `IDENTITY_WORKLOAD_ISSUER_URL`) — no config files at runtime. A Dockerfile is provided for containerized deployment.
