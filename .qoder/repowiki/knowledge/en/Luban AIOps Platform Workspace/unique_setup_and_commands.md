Workspace-wide workflow is driven by the root Makefile: `make sync` installs uv environments for all Python products, `make test` runs every product's pytest suite, `make verify` is the pre-commit/pre-push gate combining tests, kustomize overlay rendering, policy scenario validation, version lockstep, and secret-vocabulary checks, `make build` produces coordinated container images tagged `<semver>-<prefix>[-<profile>]-<gitsha>` (or `-dirty-<timestamp>` for dirty trees) and writes them to `shared/platform-ops/gitops/dev-k8s/.images.env`, and `make deploy` applies the dev-k8s overlay. Samples are installed separately via `make deploy-samples` so they never ship in the base overlay. Policy changes require editing only `shared/shared-contracts/policies/policy-default.yaml` and running `make sync-policy` to propagate to consumers.
