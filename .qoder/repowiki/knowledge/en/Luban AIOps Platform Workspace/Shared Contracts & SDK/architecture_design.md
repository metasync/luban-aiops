Two sibling sub-packages with a strict one-way dependency: `shared/shared-contracts/` is the contract source of truth (JSON Schema files under `schemas/`, a YAML policy bundle under `policies/`, validation scripts under `scripts/`, and documentation), while `shared/shared-sdk/` is a placeholder for shared client libraries that will consume those schemas. Schemas are versioned by directory prefix (v1 `chat-*` vs v2 `agent-chat-*`) and each file declares a `$id` URI so consumers can reference them independently. The module exposes no runtime code — it is a data-only boundary between `tool-gateway`, `agent-platform`, and product services, enforced by the README's explicit scope list and the `additionalProperties: false` schema constraint. Validation helpers (`validate_policy.py`, `validate_version.py`) ensure policy bundles and schema versions stay in sync before release.
