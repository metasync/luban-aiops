Build and run via the project's Makefile which includes shared fragments from `../../mk/image.mk` and `../../mk/python.mk`; the `skills-hub` console script (defined in `pyproject.toml`) invokes `skills_hub.main:run`. Environment-driven configuration uses `SKILLS_SOURCES`, `SKILLS_GIT_TOKENS`, `SKILLS_STORE_BACKEND`, `SKILLS_DB_URL`, `SKILLS_QUERY_CLIENTS`, `SKILLS_WORKLOAD_*`, and `SKILLS_AUDIT_*` variables — malformed values raise `SettingsError` at startup to fail fast.
