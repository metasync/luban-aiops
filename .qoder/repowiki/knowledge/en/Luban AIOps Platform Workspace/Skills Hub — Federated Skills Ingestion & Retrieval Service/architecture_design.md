Layered FastAPI application with clear separation of concerns: `app.py` wires lifespan (store + sync manager startup/shutdown), middleware request logging, metrics, and telemetry; `api/router.py` composes route modules (`health`, `status`, `skills`) in declaration order so static paths match before the `{skill_id}` catch-all. Business logic lives under `services/`: `ingestion.py` walks source directories and parses YAML frontmatter into `Skill` records; `sync.py` orchestrates periodic cloning/checkouts and ingestion; `skill_store.py` defines a `SkillStore` Protocol implemented by both `InMemorySkillStore` (dev/test) and `PostgresSkillStore` (deployed), selected via `build_skill_store` based on `SKILLS_STORE_BACKEND`; `scoring.py` provides shared tokenization/ranking used by both backends for byte-identical search ordering. Configuration is centralized in `core/config.py` as frozen dataclasses parsed from environment variables (`SKILLS_*`). Cross-cutting concerns live in `core/` (`config`, `metrics`, `observability`, `telemetry`, `request_context`, `runtime`). The entrypoint `main.py` exposes a `skills-hub` CLI script that runs uvicorn with runtime settings from env.
