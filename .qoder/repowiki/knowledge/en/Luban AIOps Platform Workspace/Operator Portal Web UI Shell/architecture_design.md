Entry point `main.tsx` bootstraps a single React tree with Ant Design `ConfigProvider`, the `AuthProvider` from `auth/`, and the shared dark theme tokens from `theme/`. `App.tsx` owns top-level state: current view id, session workspace (`sessions/useSessionWorkspace`), and the approvals inbox poll; it renders a responsive `Layout.Sider` whose menu items are filtered by role constants in `roles.ts` and dispatches to feature views under `views/` plus the chat workspace. Cross-cutting concerns are injected via context rather than props: `AuthContext` supplies username/roles/session to every view, while `useSessionWorkspace` is passed down to `ChatView`, `DocumentsView`, and `SettingsView` so they can pin sessions or refresh the sidebar. All data flows through the `api/` client layer, which is consumed uniformly by views and hooks; streaming chat uses the separate `stream/` transport module for SSE frames decoded into model events consumed by `chat/`. The shell enforces isolation by keeping routing as in-memory state (no router library) and gating navigation purely on roles.
