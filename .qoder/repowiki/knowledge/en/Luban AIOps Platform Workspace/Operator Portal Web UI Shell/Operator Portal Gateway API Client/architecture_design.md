Single flat module centered on `client.ts`, which exposes a shared `requestJson<T>` helper that serializes JSON bodies, injects an `x-request-id` header, attaches a Bearer token from `../auth/storage`, resolves the gateway URL via `currentGateway()` (with a `luban.portal.gatewayUrl` localStorage override), and throws a typed `ApiError` on non-2xx responses. Each domain file (`sessions.ts`, `incidents.ts`, `approvals.ts`, `documents.ts`, `models.ts`) is a thin endpoint surface: it declares TypeScript interfaces mirroring the gateway contract and exports async functions that call `requestJson` with the appropriate `/api/v1/...` path, optional `URLSearchParams`, and an optional `AbortSignal`. There are no internal sub-packages or service layers — dependency direction is one-way: domain files depend only on `client.ts` and `../auth/storage`, and callers in the UI consume these modules directly.
