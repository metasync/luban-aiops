Three-layer internal structure with a clear dependency direction: `models.ts` defines the typed wire contract (`StreamFrame` discriminated union, `DecodedEvent`, `ConfirmationStatus`, `ExecutionReceipt`); `decoder.ts` implements an incremental `SseLineDecoder` that splits on `\n\n`, parses `data:` blocks into `DecodedEvent` objects, and maps raw payloads to typed frames (delta, tool_call, tool_result, confirmation_request/result, error, terminal) while whitelisting delta event types and known pending-call actions; `transport.ts` opens HTTP requests via `fetch` to `/api/v1/chat/stream` (GET) and `/api/v1/chat/confirm` (POST), attaches auth/request-id headers, normalizes non-OK responses into `StreamOpenError` (with optional FastAPI detail envelope for 409 race resolution), and exposes `consumeStream` to pipe chunks through the decoder. `useChatStream.ts` is the single view-facing React hook that owns per-session turn state, accumulates deltas, renders HITL confirmation cards, handles session switching with a per-tab turn cache, retries on stale session 404, and drives the confirm-resume flow where POST /chat/confirm returns the resumed SSE stream that reuses the same `consumeStream` pipeline. All public surface area flows outward from this module — views consume only `useChatStream` and its exported types, never touching the decoder or transport directly.
