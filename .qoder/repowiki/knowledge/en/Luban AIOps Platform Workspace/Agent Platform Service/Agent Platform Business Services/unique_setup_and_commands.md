Backend selection is driven by environment variables: `SESSION_STORE_BACKEND` (`memory`|`redis`|`postgres`, default `memory`), `SESSION_DB_URL` (required when backend is `postgres`), `SESSION_REDIS_HOST/PORT/DB`, `SESSION_TTL_SECONDS`, `SESSION_MAX_ENTRIES`; `AGENT_GATEWAY_TOOL_AUTO_ALLOW` overrides the auto-approve tool allow-list; `SESSION_STORE_BACKEND=postgres` triggers an idempotent `CREATE TABLE IF NOT EXISTS` bootstrap of the sessions table.
