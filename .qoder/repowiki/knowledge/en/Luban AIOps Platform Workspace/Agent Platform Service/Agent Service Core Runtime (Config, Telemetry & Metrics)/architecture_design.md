A flat package of cross-cutting runtime helpers consumed by the FastAPI application. `config.py` exposes a cached `get_settings()` that lazily instantiates `RuntimeSettings.from_env()`. `env.py` provides typed env readers (`get_env_value`, `get_env_int`) used throughout. `metrics.py` declares module-level `prometheus_client` Counters/Gauges/Histograms and attaches an HTTP RED middleware plus a GET `/metrics` endpoint via `setup_metrics(app)`, keeping metric objects at module scope to avoid double-registration across test app rebuilds. `telemetry.py` implements an opt-in OTLP push pipeline gated by `OTEL_ENABLED`; `setup_telemetry(app, service_name)` initializes TracerProvider, MeterProvider, log bridge, and FastAPI/HTTPX instrumentation once per process, with all imports deferred inside the function so OTel is optional. `request_context.py` resolves a stable `x-request-id` by preferring the inbound header, then the active OTel trace id, then a generated UUID — bridging into `telemetry.current_trace_id()`. `observability.py` configures the root Python logger level from `LOG_LEVEL` and emits JSON-structured audit events via `log_event`. Dependency direction is one-way: this package depends only on stdlib, FastAPI, prometheus_client, and opentelemetry; nothing in the package imports business logic.
