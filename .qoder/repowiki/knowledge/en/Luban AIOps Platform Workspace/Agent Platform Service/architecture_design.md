The service is organized as a layered FastAPI application under `src/agent_service/`: the `api/v2` routers consume business services in `services/`, which orchestrate the runtime kernel (`runtime_kernel.py`) and pluggable provider adapters in `providers/` (OpenAI, DashScope, DeepSeek, Luban) via a registry pattern. Shared bootstrap lives in `core/` (config/env, Prometheus metrics, OpenTelemetry tracing, structured logging, request correlation) and is consumed uniformly by both entrypoints — a native FastAPI app (`native_service.py`) backed by Redis and an AgentScope Runtime agent app (`runtime_kernel.py`). Business services abstract persistence through pluggable backends (Postgres/Redis for sessions, file/object storage for evidence/execution records), while `tools/gateway_tools.py` proxies tool calls to the platform's tool-gateway. The `core/` layer plus the provider registry form the cross-cutting contract that all other layers depend on, keeping API routes stateless and delegating domain logic to services.
