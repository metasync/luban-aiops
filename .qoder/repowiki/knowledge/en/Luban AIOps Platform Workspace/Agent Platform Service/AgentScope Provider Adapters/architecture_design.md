The module defines a single abstract base `AgentScopeProvider` in `base.py` that encapsulates shared validation (API key presence, provider-name match), default model/base-url resolution via `RuntimeSettings`, and live-discovery filtering (`discover_filter`) which drops dated snapshots and non-chat modalities. Each vendor is implemented as a subclass (`openai.py`, `dashscope.py`, `deepseek.py`, `luban.py`) declaring `provider_name`, `default_model`, optional `default_base_url`, a curated `model_series` tuple, and discovery filters (`discover_family_prefixes`, `discover_exclude_markers`). The `registry.py` module statically instantiates all providers in a `_PROVIDERS` dict keyed by string name and exposes `get_provider()` (raising `ProviderConfigurationError` for unknown names) and `supported_provider_names()`. The package `__init__.py` re-exports only the public interface (`AgentScopeProvider`, `ProviderConfigurationError`, `get_provider`, `supported_provider_names`). Dependency direction is one-way: concrete providers depend on `base` and `agent_service.runtime_settings`; the registry depends on concrete providers; callers depend only on the package surface.
