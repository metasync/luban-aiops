Two-layer boundary between the HTTP contract and the AgentScope kernel:
- `schemas/` holds the single source of truth for request/response shapes. `v2.py` defines the current public contract (chat, streaming SSE, sessions, HITL confirmation records, model catalog, runtime metadata, health, operations documents) and is validated against JSON Schema files in `shared/shared-contracts/schemas/`. `api.py` keeps legacy transitional models (`SessionRecord`, `ChatRequest`, etc.) used by older surfaces.
- `api/v2/routes.py` mounts a FastAPI `APIRouter(prefix="/api/v2")` that owns every endpoint under `/api/v2/*`. Each handler extracts identity from headers (`X-User-ID`, `x-request-id`) — never from bodies — and forwards a gateway-relayed `Authorization: Bearer` token opaquely to the kernel (SPEC-008 R-5). Route logic delegates stateful work to `services.*` modules (`session_service`, `agent_state_store`, `model_catalog`, `operation_documents`, `confirmation_records`, `evidence_store`, `shift_summary`, `runtime_dependencies`) and returns typed responses via the `schemas.v2` models.
- Streaming endpoints (`/chat/stream`, `/chat/confirm`) return `StreamingResponse` with `text/event-stream`, normalizing raw kernel chunks through `_normalize_stream_event` into `AgentStreamEvent` frames using whitelists (`_STREAM_EVENT_TYPES`, `_TOOL_RESULT_STATUSES`, `_PENDING_CALL_RISK_LEVELS`, `_PENDING_CALL_ACTIONS`) so unknown fields degrade safely.
- Dependency direction is strictly inward: routes depend on `schemas.v2` and `services.*`; services are not imported by schemas. The module exposes no application bootstrap — it is mounted by an outer FastAPI app.
