Flat test package under `products/agent-platform/tests/` with one pytest file per production module (e.g. `test_runtime_kernel.py`, `test_session_service.py`, `test_postgres_session_store.py`, `test_redis_session_store.py`). Tests import the real `agent_service.*` modules and exercise them end-to-end via FastAPI's `TestClient` for HTTP routes and direct async calls for kernel/session logic. External collaborators (session stores, evidence stores, agent state stores, tool gateway) are injected by monkeypatching module-level attributes such as `SESSION_STORE`, `AGENT_STATE_STORE`, `EVIDENCE_STORE`, or `_build_agent`, so each test runs in isolation without real databases. Async code is driven through `asyncio.run()` inside synchronous test functions, and concurrency properties (agent cache deduplication, LRU eviction races) are verified by spawning concurrent tasks with `asyncio.gather`.
