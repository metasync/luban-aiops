Entrypoint is the console script `incident-service = incident_service.main:run` defined in `pyproject.toml`; build uses `uv_build` backend. Docker image name is set via `IMAGE_NAME := incident-service` and shared Makefile fragments under `../../mk/image.mk` and `../../mk/python.mk` are included, so standard targets like `make build`, `make test`, `make image` are available from this directory.
