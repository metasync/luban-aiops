The repository is organized as a product-oriented monorepo under `products/`, where each directory is an independently buildable, Dockerized service with its own `pyproject.toml`, `Dockerfile`, `Makefile`, and `tests/`. Cross-cutting concerns live in `shared/`: `shared/shared-contracts` defines JSON schemas and policy YAMLs that all products consume; `shared/platform-ops` holds Kustomize overlays (`gitops/dev-k8s`, `runtime-profiles/*`) and helper scripts; `shared/base-images/base-uv` provides a common uv-based Python image. The root `Makefile` orchestrates cross-product workflows: it enumerates `PYTHON_PRODUCTS` and `IMAGE_PRODUCTS`, delegates per-product `test`/`build`/`lint` targets via `make -C products/<name>`, renders Kustomize overlays, validates the canonical policy bundle against `shared/shared-contracts/policies/policy-default.yaml`, enforces version lockstep via `VERSION`, and drives coordinated deploy through `shared/platform-ops/gitops/dev-k8s/deploy.sh`. End-to-end demos run via `make e2e` against a deployed cluster. Documentation follows spec-driven development: `docs/specs/SPEC-NNN-*` directories pair plan/spec/tasks, `docs/adr/` records architectural decisions, and `docs/agentic-aiops-platform/release-notes/` tracks releases.
