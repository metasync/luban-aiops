The repository is a product-oriented monorepo under `products/`, where each directory is a self-contained Python service (agent-platform, identity-broker, platform-gateway, tool-gateway, audit-service, incident-service, skills-hub, operator-portal) with its own `src/<package>/`, `tests/`, `Dockerfile`, `Makefile`, and `pyproject.toml`. Cross-cutting concerns live in `shared/`: `shared/shared-contracts` holds JSON schemas and policy YAMLs that all products consume; `shared/platform-ops/gitops/dev-k8s` contains Kustomize overlays used by `make deploy`; `shared/base-images/base-uv` provides the uv-based Python base image. The root `Makefile` aggregates per-product routines via `PYTHON_PRODUCTS` and `IMAGE_PRODUCTS` lists, builds coordinated images tagged from the single `VERSION` file, renders Kustomize overlays, validates policy/version lockstep, and runs e2e demo scripts under `shared/platform-ops/e2e`. Dependency direction flows outward from shared contracts into products; products communicate over HTTP APIs defined by those contracts rather than direct imports. Architecture decisions are tracked as ADRs under `docs/adr/`, feature specs as plan/spec/tasks triples under `docs/specs/SPEC-NNN-*`, and release notes under `docs/agentic-aiops-platform/release-notes/`.
