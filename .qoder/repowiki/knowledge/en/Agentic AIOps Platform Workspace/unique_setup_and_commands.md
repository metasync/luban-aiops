Use the root `Makefile` as the single entry point: `make sync` installs deps across all Python products, `make test` runs every product's pytest suite, `make build` builds all container images with a coordinated `<semver>-<prefix>[profile]-<sha>` tag and writes it to `shared/platform-ops/gitops/dev-k8s/.images.env`, `make deploy` invokes `shared/platform-ops/gitops/dev-k8s/deploy.sh`, `make e2e` runs demo scripts against a deployed cluster, and `make verify` is the pre-commit/pre-push gate combining tests, overlay rendering, policy validation, and version lockstep checks. Per-product commands are available via `make -C products/<name> help`.
