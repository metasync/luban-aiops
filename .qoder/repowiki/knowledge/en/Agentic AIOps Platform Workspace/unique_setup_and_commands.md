Run `make verify` as the pre-commit/pre-push gate (runs every product's tests, renders Kustomize overlays, validates the canonical policy YAML, and checks version lockstep). `make build` builds all images with a coordinated tag derived from `VERSION` and writes `.images.env`; `make deploy` invokes `shared/platform-ops/gitops/dev-k8s/deploy.sh`; `make e2e` executes demo scripts against a deployed cluster after port-forwarding `platform-gateway` and `identity-service`. Per-product commands are available via `make -C products/<name> help`.
