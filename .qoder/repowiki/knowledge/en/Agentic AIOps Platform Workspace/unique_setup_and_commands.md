Use the root `Makefile` as the single workflow surface: `make verify` runs every product's test suite, renders all Kustomize overlays, validates the canonical policy bundle, and checks version lockstep across products; `make build` builds all product images with a coordinated tag derived from `VERSION` and writes `.images.env`; `make deploy` invokes `shared/platform-ops/gitops/dev-k8s/deploy.sh`; `make e2e` runs end-to-end demo scripts against a deployed cluster after port-forwarding `platform-gateway` and `identity-service`; per-product commands are available via `make -C products/<name> help`. Policy synchronization uses `make sync-policy` to copy `shared/shared-contracts/policies/policy-default.yaml` into each consumer and the k8s base overlay.
