Use the root `Makefile` as the single entry point: `make verify` runs every product's test suite, renders all Kustomize overlays, validates the canonical policy bundle, and enforces version lockstep; `make build` builds all product images with a coordinated `<semver>-<prefix>[-<profile>]-<gitsha>` tag and writes `.images.env`; `make deploy` invokes `shared/platform-ops/gitops/dev-k8s/deploy.sh`; `make e2e` runs demo scripts against a deployed cluster after port-forwarding `platform-gateway:18083` and `identity-service:18081`. Per-product commands are available via `make -C products/<name> help`. Policy changes must be propagated through `make sync-policy` to copy the canonical `shared/shared-contracts/policies/policy-default.yaml` into each consumer.
