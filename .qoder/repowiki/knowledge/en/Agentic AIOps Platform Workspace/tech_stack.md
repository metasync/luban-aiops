Python services managed with `uv` (lockfiles + `.python-version` pinning), FastAPI-style apps built around a common `core/` bootstrap (config, metrics, observability, telemetry, request context); Node/React web UI under `operator-portal/web-ui`; Kubernetes deployments via Kustomize overlays; Docker images tagged with a coordinated semver+gitsha scheme; JSON Schema validation for all cross-service contracts.
