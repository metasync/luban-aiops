Python services managed with `uv` (lockfile + environment), packaged into container images built from per-product `Dockerfile`s on top of a shared `shared/base-images/base-uv` base image; Kubernetes deployment via Kustomize overlays under `shared/platform-ops/gitops/dev-k8s`; OpenTelemetry-based observability conventions defined in `shared/shared-contracts/observability-conventions.md`; JSON Schema validation for inter-service contracts.
