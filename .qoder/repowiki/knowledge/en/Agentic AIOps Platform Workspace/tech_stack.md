Python services built with `uv` (environment + package manager) on official `uv` base images; FastAPI-style service layout (`app.py`/`main.py`/`api/routes`); React/Vite web UI for the operator portal; Kustomize-based GitOps overlays under `shared/platform-ops/gitops`; JSON Schema files in `shared/shared-contracts/schemas` define cross-service contracts; YAML policy bundles validated via a shared script.
