The application is layered around a single FastAPI app bootstrapped in `app.py`/`main.py`, which wires together the four child concerns: `schemas_and_app` defines the Pydantic skill envelope and lifespan-managed services; `core_runtime` supplies shared configuration, request-scoped identity (`request_context`), logging, Prometheus metrics, and optional OpenTelemetry telemetry consumed by every layer; `services` implements ingestion, scoring, storage (in-memory or PostgreSQL), sync orchestration, and query authentication; `api_routes` mounts route handlers under `/api/v1` that call into those services. Tests in `tests/` mirror this layering, asserting both unit behavior of individual services and end-to-end contract alignment against the Pydantic schemas.
