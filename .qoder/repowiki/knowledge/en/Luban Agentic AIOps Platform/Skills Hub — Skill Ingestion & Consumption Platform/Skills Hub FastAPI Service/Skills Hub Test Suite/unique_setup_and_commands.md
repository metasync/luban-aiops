Route tests configure the app by patching `os.environ` keys (`SKILLS_STORE_BACKEND`, `SKILLS_SOURCES`, `SKILLS_QUERY_CLIENTS`, `SKILLS_SYNC_INTERVAL_SECONDS`) and calling `get_settings.cache_clear()` before constructing a `TestClient`; they then poll `/api/v1/skills/status` until the source reports accepted records, since the lifespan-driven sync loop runs asynchronously. Ingestion and sync tests use `tempfile.TemporaryDirectory` fixtures created in `setUp` and cleaned up in `tearDown`. Postgres store tests inject a fake `connect` callable that returns a mock connection/cursor instead of requiring a real database.
