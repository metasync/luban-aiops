Flat collection of `unittest.TestCase` modules under `products/skills-hub/tests/`, each targeting a specific subsystem of the skills-hub application: `test_ingestion.py` validates YAML frontmatter parsing and slug generation via `skills_hub.services.ingestion`; `test_scoring.py` asserts deterministic title/tag/body weighting and excerpt bounds in `skills_hub.services.scoring`; `test_skill_store.py` exercises both `InMemorySkillStore` and a `PostgresSkillStore` backed by an inline fake psycopg driver; `test_sync.py` drives the `SyncManager` over temp directories and mocks git checkout to verify atomic snapshot swaps and credential scrubbing; `test_routes.py` boots the real FastAPI app through `fastapi.testclient.TestClient` with environment-driven settings (memory store, local source) and polls `/api/v1/skills/status` until sync completes; `test_contracts.py` cross-validates the Pydantic `Skill` model against the shared JSON schema at `shared/shared-contracts/schemas/skill.schema.json`; `test_query_auth.py`, `test_config.py`, and `test_validate_cli.py` cover query client auth, configuration loading, and CLI validation respectively. Tests depend only on the application package (`skills_hub.*`) and standard libraries — no external services are required except when a test explicitly patches or mocks them.
