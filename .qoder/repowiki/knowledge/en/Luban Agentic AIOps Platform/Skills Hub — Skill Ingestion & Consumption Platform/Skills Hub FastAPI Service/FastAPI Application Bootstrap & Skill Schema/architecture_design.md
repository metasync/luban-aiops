Two-layer entry point: `main.py` is a thin CLI-style runner that loads `SkillsRunSettings` from environment and starts Uvicorn; `app.py` constructs the `FastAPI` instance via `create_app()`, registers an HTTP middleware for request tracing, mounts the API router from `skills_hub.api.router`, and wires up observability (`configure_logging`, `setup_metrics`, `setup_telemetry`). The `lifespan` context manager owns long-lived resources — it builds a `SkillStore` from settings, prunes stale source rows on startup, attaches both the store and a `SyncManager` to `app.state`, and ensures they are stopped/closed in reverse order. The `schemas/` sub-package holds shared Pydantic models used across the app; currently only `skill.py` defines the `Skill` envelope bound to `skill.schema.json` (SPEC-014 R-1) with strict validation and a `summary()` helper that serializes without the body payload.
