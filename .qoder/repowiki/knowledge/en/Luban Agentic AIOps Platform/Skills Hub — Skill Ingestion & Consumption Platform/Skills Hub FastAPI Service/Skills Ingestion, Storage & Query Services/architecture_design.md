The module is organized as a set of single-responsibility service modules with a clear dependency direction: `sync.py` orchestrates per-source async loops that call `ingestion.py` to parse/validate Markdown into `Skill` records, then atomically swap snapshots via the `SkillStore` protocol defined in `skill_store.py`. `skill_store.py` implements two backends — `InMemorySkillStore` (dev/test) and `PostgresSkillStore` (production, using `psycopg` async connections and a GIN full-text index) — selected by `build_skill_store()` based on `SKILLS_STORE_BACKEND`. Both backends delegate ranking to the pure function `scoring.rank`, guaranteeing byte-identical ordering across stores. `query_auth.py` provides two authentication paths (HTTP Basic against a static client registry and Kubernetes workload JWT via OIDC discovery/JWKS) exposed through `authenticate_caller`. Cross-cutting concerns are isolated: ingestion uses dataclasses (`Rejection`, `IngestResult`) for validation results; scoring exposes a tokenization regex and fixed weights so both backends compute identical scores; sync tracks per-source `SourceStatus` and reports bounded rejection lists.
