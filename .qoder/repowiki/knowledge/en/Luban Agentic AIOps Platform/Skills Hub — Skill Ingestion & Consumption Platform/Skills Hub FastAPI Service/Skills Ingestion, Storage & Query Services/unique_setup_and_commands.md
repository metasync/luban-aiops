PostgreSQL backend requires `SKILLS_STORE_BACKEND=postgres` plus a `SKILLS_DB_URL`; the store auto-creates the `skills` table and GIN index on first `initialize()`. Git-backed sources are materialized via shallow `git clone --depth 1` with optional `x-access-token` injected into HTTPS URLs, and Kubernetes ConfigMap/Secret mounts are read from the projected `..data` directory to avoid symlink artifacts.
