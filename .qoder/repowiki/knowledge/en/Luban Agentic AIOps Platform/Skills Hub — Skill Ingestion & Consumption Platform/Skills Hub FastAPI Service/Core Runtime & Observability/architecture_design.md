The module is a flat package of independent infrastructure helpers consumed by the rest of skills-hub. `config.py` defines frozen dataclasses (`SkillsSettings`, `SourceSpec`, `QueryClient`, `WorkloadClient`) parsed from `SKILLS_*` environment variables via dedicated `parse_*` functions, with a single `@lru_cache(maxsize=1)`-backed `get_settings()` singleton. `runtime.py` provides a separate `SkillsRunSettings` dataclass for host/port resolution (with Kubernetes-friendly port parsing). `metrics.py` registers global `prometheus_client` counters/gauges/histograms and attaches a RED HTTP middleware plus a `/metrics` endpoint to any FastAPI app via `setup_metrics`. `telemetry.py` is an opt-in OTel push pipeline gated by `OTEL_ENABLED`; it lazily imports OTel SDK components, configures tracing + metrics providers once, instruments FastAPI and HTTPX, and exposes `current_trace_id()`. `request_context.py` resolves a stable per-request correlation ID by preferring an inbound header, then falling back to the active OTel trace id, then a UUID. `observability.py` centralizes root logger configuration and a `log_event` helper that emits JSON-structured log records. Dependency direction is one-way: `request_context` depends on `telemetry`; all other modules are independent and imported by higher layers.
