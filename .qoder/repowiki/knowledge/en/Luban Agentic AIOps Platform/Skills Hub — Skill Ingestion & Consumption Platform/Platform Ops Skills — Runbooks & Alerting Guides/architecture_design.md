Two parallel skill source trees under `shared/platform-ops/skills/`, each representing a distinct team's knowledge base that the skills hub ingests as Markdown skills:
- `platform-runbooks/guides/` — problem-oriented troubleshooting guides (e.g. CrashLoopsAndOOM, DebugPods) keyed by human-readable file names.
- `sre-alerting/alerts/` — alert-oriented runbooks named after Prometheus alert rules (e.g. KubePodCrashLooping) so alert → runbook lookup works via tag matching.
Both directories follow the same contract defined in `shared/shared-contracts/skill-format.md`: each Markdown file carries YAML frontmatter with `title`, `description`, optional `tags`, `version`, and `source_url`. The two sources intentionally overlap on pod crash topics but are distinguished by namespace (`platform-runbooks/...` vs `sre-alerting/...`) and deterministic scoring so the agent can cite both perspectives. Each sub-source ships its own `README.md` documenting contribution steps and a `NOTICE` file for upstream attribution (Kubernetes docs CC-BY-4.0, prometheus-operator runbooks Apache-2.0). Validation is performed via `python -m skills_hub.validate <source-path>` before publishing.
