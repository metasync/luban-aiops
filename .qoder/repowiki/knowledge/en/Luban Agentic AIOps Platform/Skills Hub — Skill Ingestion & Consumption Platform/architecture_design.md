The module wires three layers around a single contract: `products/skills-hub/` implements the ingestion pipeline (Markdown parsing → scoring → pluggable store) and FastAPI routes; `shared/platform-ops/skills/` provides concrete skill source documents (Kubernetes runbooks and SRE alerting guides) consumed by the hub's agent; `shared/shared-contracts/schemas/skill.schema.json` plus `skill-format.md` define the canonical Markdown skill schema that both the producer (platform ops docs) and consumer (skills hub parser) must follow. Cross-child communication is therefore one-directional: platform ops skills are authored against the shared schema, and the skills hub validates and indexes them via that same schema, keeping content authoring decoupled from runtime ingestion.
