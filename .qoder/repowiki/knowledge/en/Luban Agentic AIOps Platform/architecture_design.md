The workspace is organized as independent Python FastAPI services under `products/` (agent-platform, identity-broker, platform-gateway, tool-gateway, audit-service, skills-hub, operator-portal) plus shared assets in `shared/`. Cross-service boundaries are enforced by JSON schemas and YAML policies in `shared/shared-contracts/schemas` and `policies/policy-default.yaml`, which every consumer validates at build time. The root `Makefile` orchestrates the lifecycle: it iterates over `PYTHON_PRODUCTS` for `sync`/`test`, builds container images with a coordinated tag written to `.images.env`, renders all Kustomize overlays under `shared/platform-ops/gitops`, and deploys via `deploy.sh`. Policy bundles are synchronized from a single canonical file into each gateway's `policies/` directory so enforcement logic stays identical across platform-gateway and tool-gateway. Services communicate over HTTP using the v1/v2 agent-chat/session/stream-event schemas; identity tokens issued by identity-broker are verified via JWKS by consumers without tight coupling. Observability follows the conventions in `shared/shared-contracts/observability-conventions.md` (Prometheus `/metrics`, OTLP opt-in, `x-request-id` bridging).
