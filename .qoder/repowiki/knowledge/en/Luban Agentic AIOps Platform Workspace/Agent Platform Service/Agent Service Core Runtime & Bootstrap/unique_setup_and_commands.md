Run the service directly via `python -m agent_service.main` or import `run()`; host/port are controlled by `AGENT_SERVICE_HOST` and `AGENT_SERVICE_PORT` (defaults `0.0.0.0:8000`). Logging level is set via `LOG_LEVEL`. Telemetry push is disabled by default and enabled only when `OTEL_ENABLED` is truthy, sending to `OTEL_EXPORTER_OTLP_ENDPOINT` with auth via `OTEL_EXPORTER_OTLP_HEADERS`.
