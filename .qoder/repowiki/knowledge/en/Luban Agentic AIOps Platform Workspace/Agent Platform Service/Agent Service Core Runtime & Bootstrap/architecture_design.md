The module is split into two layers. The top-level package files form the process bootstrap: `main.py` is the CLI entrypoint that reads `AGENT_SERVICE_HOST/PORT`, initializes settings via `core.config.get_settings()`, and starts Uvicorn with the `app` object; `app.py` constructs the FastAPI instance, registers an HTTP middleware for structured request logging, mounts the v2 router from `agent_service.api.v2.routes`, attaches Prometheus metrics and OTel telemetry, and runs a lifespan task that launches model discovery when configured; `agent_app.py` re-exports the native AgentScope runtime app from `entrypoints.runtime`; `metadata.py` centralizes service identity constants (name, title, version, default ports). The `core/` subpackage provides framework-agnostic infrastructure consumed by `app.py`: `config.py` caches a singleton `RuntimeSettings` loaded from environment variables; `env.py` offers typed env helpers (`get_env_value`, `get_env_int`) supporting multiple fallback names; `observability.py` configures the root logger and emits JSON-structured events via `log_event`; `metrics.py` defines module-level Prometheus counters/gauges/histograms plus a RED middleware and a `/metrics` endpoint, with dedicated metric groups for sessions, chat, session store backends, agent state stores, evidence store, audit emission, and model discovery; `telemetry.py` implements an opt-in OpenTelemetry push pipeline gated by `OTEL_ENABLED`, initializing TracerProvider, MeterProvider, log bridge, and FastAPI/HTTPX instrumentation once per process; `request_context.py` resolves the `x-request-id` correlation key by preferring the inbound header, then the active OTel trace id, then a generated UUID. Dependency direction is strictly inward: `main.py` → `app.py` → `core/*`; business logic lives in sibling packages (`api`, `services`) and depends on this core layer only.
