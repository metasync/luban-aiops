Two sibling modules expose independent `run()` entry points for the agent platform, each assembling a distinct application server:
- `native.py` builds an AgentScope FastAPI app via `agentscope.app.create_app`, wiring `RedisStorage`, `RedisMessageBus`, and a `LocalWorkspaceManager` whose connection parameters are read from `AGENTSCOPE_*` / `AGENT_NATIVE_*` environment variables through the `NativeServiceSettings` dataclass. The resulting ASGI app is launched with `uvicorn.run`.
- `runtime.py` builds an `AgentApp` (from `agentscope_runtime.engine.app`) using a lazy-import strategy so the optional `agentscope-runtime` dependency can be absent at import time; it registers a single `@agent_app.query(framework="agentscope")` handler that streams events from an underlying agent via `stream_agent_reply`, translating `TEXT_BLOCK_DELTA` / `THINKING_BLOCK_DELTA` / `REPLY_END` events into `Msg` objects with block-based content. Session state is loaded/saved through an optional session manager attached to the app state, and errors are captured via `kernel.remember_error`.
Both modules depend only on `agent_service.core.*`, `agent_service.metadata`, and `agent_service.runtime_kernel`; they do not import each other, keeping the two runtimes decoupled and independently deployable.
