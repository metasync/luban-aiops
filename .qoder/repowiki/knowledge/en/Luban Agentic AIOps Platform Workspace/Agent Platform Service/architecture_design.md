The service is layered around a single FastAPI application bootstrapped by `core_runtime` (logging, metrics, OpenTelemetry, request context) and started via two entrypoints in `entrypoints` — a native FastAPI app backed by Redis and a runtime `AgentApp` wrapper. HTTP requests hit `api_routes` (`/api/v2` routers + Pydantic schemas), which delegate to `services` that orchestrate per-session state, execution records, evidence, skills, secrets, and HITL confirmations. Each session turn runs inside the `runtime_kernel`, which wraps AgentScope to drive turns, stream events, bridge HITL confirmations, and persist signed executions. Model backends are abstracted behind `providers` (OpenAI, DashScope, DeepSeek, Luban) selected from runtime settings via a registry. Tests under `tests/` exercise every layer against in-memory or fake backends, keeping the kernel, providers, and services independently testable.
