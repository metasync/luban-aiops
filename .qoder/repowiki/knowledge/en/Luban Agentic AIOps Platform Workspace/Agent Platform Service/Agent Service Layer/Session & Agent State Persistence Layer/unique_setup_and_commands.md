Backend selection is driven entirely by environment variables: `SESSION_STORE_BACKEND` (memory|redis|postgres, default memory), `SESSION_DB_URL` (required when postgres), `SESSION_TTL_SECONDS`, `SESSION_MAX_ENTRIES`, `SESSION_REDIS_HOST/PORT/DB`; and `AGENT_STATE_STORE_BACKEND` (memory|postgres, default memory), `AGENT_STATE_DB_URL`, `AGENT_STATE_TTL_SECONDS`. Unknown backend values raise at startup; Postgres initialization failure triggers a logged fallback to in-memory.
