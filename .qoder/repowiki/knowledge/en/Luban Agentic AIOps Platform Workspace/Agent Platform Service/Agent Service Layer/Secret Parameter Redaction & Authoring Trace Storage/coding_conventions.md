- Secret detection is centralized in `secret_params.py` as named predicates (`is_secret_param`, `is_opaque_value`, `is_known_safe`, `should_mask`) plus a fail-closed allow-list (`KNOWN_SAFE_FIELDS`) — callers never re-implement name matching.
- Each masking function returns a fresh structure rather than mutating inputs, documented explicitly so callers know the original `parameters` used for `args_digest` signing stays untouched.
- Cross-product vocabulary copies (gateway `_SECRET_QUERY_PARAMS`, skills-hub `CREDENTIAL_HOLE`) are kept as Python constants and enforced by the `validate_secret_vocabulary.py` build check instead of runtime config files, avoiding open-failure on missing mounts.
- Backend selection follows a Protocol + dual-implementation pattern: `AuthoringTraceStore` Protocol with `InMemoryAuthoringTraceStore` and `PostgresAuthoringTraceStore` share identical method signatures, state names, and timestamp normalization so callers treat them interchangeably.
- Per-session concurrency on Postgres is serialized via `pg_advisory_xact_lock` keyed by a CRC32 of `session_id` under a fixed lock class, applied before both `append_step` and `close_trace`.
- Streaming redaction defers emission by holding a tail whose length is computed from the longest possible match (literal, URL scheme prefix, or pinned-shape anchor) and only releases it when no match straddles the cut point.
