The Postgres backend requires `AGENT_STATE_STORE_BACKEND=postgres` together with a valid `AGENT_STATE_DB_URL`; missing URL raises during construction. On startup the Postgres store runs its own `CREATE TABLE IF NOT EXISTS` DDL and a retention sweep deleting rows older than 30 days (bounded by `_SWEEP_LIMIT=100`). Worker handoff timing is controlled by `RuntimeSettings.execution_worker_timeout_seconds` (default 60s) and configured via `AGENT_EXECUTION_WORKER_TIMEOUT_SECONDS`.
