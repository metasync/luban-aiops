Flat collection of pytest modules under `products/agent-platform/tests/`, each file targeting a subsystem of `agent_service` (e.g. `test_app.py` hits the FastAPI `create_app` via `fastapi.testclient.TestClient`; `test_entrypoints.py` mocks `Msg`, `AgentApp`, and `get_runtime_kernel` to validate native/runtime entrypoint behavior; `test_postgres_session_store.py` and `test_redis_session_store.py` exercise the session store factory with a hand-rolled fake psycopg driver and `fakeredis`, respectively). Tests import production code directly from `agent_service.*` rather than through a test package, keeping one test module per source concern. Fixture-driven isolation is used where needed (e.g. `redis_client`, `redis_store` fixtures), while most tests construct lightweight fakes inline (`FakeKernel`, `FakeAgent`, `FakeSessionManager`, `FakeUserMsg`) and drive async code via `asyncio.run`. No shared conftest was found at this scope; configuration is per-file.
