The app is a single Python package under `app/src/acme_admin/` built around one module-level singleton `STORE` (in `store.py`) that holds seeded `User` dataclass records plus a monotonic revision counter. `main.py` assembles the FastAPI application: it enforces fail-closed startup via a lifespan hook that raises if `ACME_ADMIN_PASSWORD` is absent, mounts two routers — `api.py` for machine endpoints (`/healthz`, `/api/hello`, `/api/users*`, `/internal/reset-demo`) and `pages.py` for six server-rendered HTML pages — and registers a single exception handler for `AdminAuthRequired`. Authentication in `auth.py` supports two mechanisms over one password: HTTP Basic via a FastAPI `Depends(require_admin)` on every `/api/users*` route, and an opaque in-memory session cookie (`acme_session`) for HTML routes checked through `session_user(request)`. Templates are embedded `string.Template` constants rendered by a `_page()` helper so the Docker image copies only one tree. Deployment artifacts under `deploy/` pin `replicas: 1` because the in-memory store cannot be shared across pods; `deploy.sh` applies manifests and asserts health, API hello, and authenticated endpoints. Four sibling sample directories (`health-check`, `user-status`, `lock-unlock-user`, `password-reset`, plus `adhoc-password-reset` and `skill-graduation`) each ship a skill document, demo script, and walkthrough orchestrated by the top-level `demo-suite.sh`.
