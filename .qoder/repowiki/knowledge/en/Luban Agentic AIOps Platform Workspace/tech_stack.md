Python services managed with `uv` (per-product `pyproject.toml` + `uv.lock`); FastAPI-based HTTP entrypoints; Docker images built from per-product `Dockerfile`s using a shared `base-uv` image; Kubernetes deployment via Kustomize overlays; Playwright headless browser connector in tool-gateway; PostgreSQL and Redis backends for session/audit stores; OpenTelemetry metrics/tracing gated by `OTEL_ENABLED`; JSON Schema validation for all inter-service contracts.
