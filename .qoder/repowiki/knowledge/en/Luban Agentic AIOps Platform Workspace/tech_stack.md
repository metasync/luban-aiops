Python services managed with `uv` (single interpreter pinned by `.python-version`); container base image is Amazon Linux 2023 + `uv` (`luban-aiops/base-uv`). Kubernetes deployment via kustomize overlays under `shared/platform-ops/gitops`. Dashboards are OpenObserve config-as-code validated offline. Operator portal is a non-uv SPA tested with Vitest and built with Vite/tsc.
