Four cohesive sub-components under `platform_gateway/core` plus one service:
- `audit_emitter.py` (services layer): builds an envelope conforming to the shared `audit-event.schema.json` contract via `build_audit_event`, then dispatches it asynchronously on a daemon thread (`threading.Thread`) over HTTP POST to `/api/v1/audit/events` using `httpx` with a 2s timeout. Failures are swallowed and counted via `record_audit_emit`; when `PLATFORM_GATEWAY_AUDIT_SERVICE_URL` is unset the call is a no-op so the audit path never degrades the gateway.
- `metrics.py`: always-on Prometheus surface built directly on `prometheus_client`. Module-level `Counter`/`Histogram` objects are registered once in the default registry; a FastAPI HTTP middleware records RED metrics per templated route and exposes GET `/metrics` (excluded from OpenAPI). Helper recorders (`record_policy_decision`, `record_token_verification`, `record_delegation_exchange`, `record_delegation_cache`, `record_audit_emit`) are the single write point for each metric family.
- `telemetry.py`: opt-in OpenTelemetry push pipeline gated by `OTEL_ENABLED`. On first `setup_telemetry(app, service_name)` call it lazily imports OTel SDK, creates a `Resource` with `service.name`, installs `TracerProvider`+`BatchSpanProcessor`, `MeterProvider`+`PeriodicExportingMetricReader`, attaches a log bridge that mirrors structured JSON logs into OTLP, instruments FastAPI and `httpx`, and sets up OTLP HTTP/protobuf export to `OTEL_EXPORTER_OTLP_ENDPOINT` (with auth via `OTEL_EXPORTER_OTLP_HEADERS`). Errors during setup are logged and ignored (fail-open); `current_trace_id()` exposes the active W3C trace id for enrichment.
- `observability.py`: minimal logging bootstrap — raises root logger level from Uvicorn's default WARNING to INFO (overridable via `LOG_LEVEL`) so structured `log_event` JSON lines survive, and emits them as sorted-key JSON payloads.
Dependency direction: `audit_emitter` depends on `core.metrics`; `telemetry` is independent; `observability` is consumed at startup before any request handling.
