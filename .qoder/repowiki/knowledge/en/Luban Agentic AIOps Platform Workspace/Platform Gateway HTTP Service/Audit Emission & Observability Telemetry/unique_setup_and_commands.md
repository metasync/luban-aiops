Enable OTel push by setting `OTEL_ENABLED=1` and pointing `OTEL_EXPORTER_OTLP_ENDPOINT` at an OTLP receiver (e.g. OpenObserve `/api/{org}/v1/{signal}`); authentication is supplied through `OTEL_EXPORTER_OTLP_HEADERS`. Audit emission requires `PLATFORM_GATEWAY_AUDIT_SERVICE_URL` plus `audit_client_id`/`audit_client_secret`; without it the emitter is a no-op. Logging verbosity can be tuned via `LOG_LEVEL`.
