- Each product directory is self-contained with its own `pyproject.toml`, `.python-version`, `Dockerfile`, `Makefile`, `src/<package>/`, and `tests/`, and is invoked from the root Makefile via `make -C products/<name> <target>` rather than being imported directly.
- Cross-product contracts (schemas, policies, SQL, scripts) are authored once under `shared/shared-contracts/` and copied into consumers by root Makefile targets (`sync-policy`, `validate-version`, `validate-secret-vocabulary`, `validate-password-policy`) instead of being duplicated or referenced as a package dependency.
- Feature development follows a spec-driven workflow where each change lives in `docs/specs/SPEC-NNN-<name>/` containing `plan.md`, `spec.md`, and `tasks.md`, with release notes recorded chronologically under `docs/agentic-aiops-platform/release-notes/`.
- Container images use a coordinated tag derived from the root `VERSION` file plus git SHA/dirty status, and all product images share the `luban-aiops/base-uv` base image built from `shared/base-images/base-uv/Dockerfile`.
- Samples and tutorial skills are kept out of the base Kustomize overlay and installed separately via `make deploy-samples` / `make deploy-sample-app` so they do not participate in the default platform deployment.
