The workspace is organized as a multi-product monorepo where each `products/<name>/` directory is an independently versioned FastAPI service (agent-platform, identity-broker, platform-gateway, tool-gateway, audit-service, incident-service, execution-runtime, skills-hub, operator-portal) communicating via JSON Schema contracts and policy bundles defined in `shared/shared-contracts/`. The top-level `Makefile` is the single orchestrator: it enumerates Python products (`PYTHON_PRODUCTS`) and image-producing products (`IMAGE_PRODUCTS`), delegates per-product `sync/test/lint/build/push` targets into each product's own Makefile, renders Kustomize overlays under `shared/platform-ops/gitops`, synchronizes the canonical policy bundle to every consumer via `make sync-policy`, validates version lockstep against the single source of truth `VERSION`, and writes a coordinated `.images.env` consumed by `make deploy` to push the dev-k8s overlay. Cross-cutting concerns — policy scenario validation, secret-vocabulary checks, overlay rendering, and e2e demo scripts — are enforced centrally so each product stays decoupled while remaining release-coordinated.
