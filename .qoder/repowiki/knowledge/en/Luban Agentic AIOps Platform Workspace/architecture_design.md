The workspace is a multi-product monorepo organized under `products/` where each service is an independent uv-managed Python package with its own `pyproject.toml`, `.python-version`, `Dockerfile`, `Makefile`, `src/<service>/`, and `tests/`. Cross-cutting concerns live in `shared/`: `shared-contracts/` holds versioned Pydantic schemas, SQL, policy definitions, and scripts consumed by every product; `shared/platform-ops/` provides GitOps overlays, dashboards, e2e tests, and skill fixtures; `shared/base-images/base-uv/` defines the common container base. The top-level `mk/*.mk` Makefiles (`defaults.mk`, `image.mk`, `python.mk`) provide shared build rules invoked from each product's `Makefile`. Documentation follows spec-driven development: `docs/specs/SPEC-NNN-<title>/` directories carry plan/spec/tasks triads, `docs/adr/` records architectural decisions, `docs/guides/` contains operator/user runbooks, and `docs/agentic-aiops-platform/release-notes/` tracks releases chronologically. `samples/acme-admin/` demonstrates end-to-end usage of the platform's skills, composition, and acceptance test harness. Dependency direction flows inward: products depend on `shared/shared-contracts` and `shared/shared-sdk`; nothing in `shared/` depends on any product.
