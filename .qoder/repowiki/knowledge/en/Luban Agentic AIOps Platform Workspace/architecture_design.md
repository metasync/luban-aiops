The root orchestrates a multi-product platform where each `products/<name>/` directory is an independently versioned FastAPI service (agent-platform, identity-broker, platform-gateway, tool-gateway, audit-service, incident-service, execution-runtime, skills-hub, operator-portal) that communicates via the JSON Schema contracts and policy bundles defined in `shared/shared-contracts/`. The top-level `Makefile` is the single entry point: it enumerates Python products (`PYTHON_PRODUCTS`) and image-producing products (`IMAGE_PRODUCTS`), delegates per-product `sync/test/lint/build/push` targets, renders Kustomize overlays under `shared/platform-ops/gitops`, synchronizes the canonical policy bundle to every consumer, validates version lockstep against the single source of truth `VERSION`, and writes a coordinated `.images.env` used by `make deploy` to push the dev-k8s overlay. Cross-cutting concerns — policy validation, secret-vocabulary checks, overlay rendering, and e2e demo scripts — are enforced centrally so each product stays decoupled while remaining release-coordinated.
