The repository is a product-oriented monorepo. `products/` holds ten independent build units (agent-platform, audit-service, execution-runtime, identity-broker, incident-service, operator-portal, platform-gateway, policy-center, skills-hub, tool-gateway), each with its own `pyproject.toml`, `.python-version`, `Dockerfile`, `Makefile`, `src/<package>/`, and `tests/`. Cross-cutting assets live in `shared/shared-contracts` (API/event/policy/domain schemas, SQL, scripts), `shared/platform-ops` (Kustomize GitOps overlays under `gitops/dev-k8s`, dashboards, e2e scripts, skills), and `shared/base-images/base-uv` (the Amazon Linux 2023 + uv base image). The root `Makefile` is the single orchestration point: it enumerates `PYTHON_PRODUCTS` and `IMAGE_PRODUCTS`, delegates per-product `sync/test/lint/build/push` via `make -C products/<name>`, computes a coordinated `IMAGE_TAG` from `VERSION` plus git state, writes `.images.env`, and runs cross-cutting gates (`overlays`, `validate-dashboards`, `validate-policy`, `validate-version`, `validate-secret-vocabulary`, `validate-password-policy`, `portal-test`, delegated-custody/runtime/multiproc/edge tests, execution-failure test) through `make verify`. `docs/specs/SPEC-NNN-*` directories follow a plan/spec/tasks triad driving release slices; `docs/adr/` records architectural decisions; `docs/agentic-aiops-platform/release-notes/` tracks delivered features. `samples/acme-admin` is an out-of-band sample application deployed separately from the base overlay per SPEC-050 R-11.
