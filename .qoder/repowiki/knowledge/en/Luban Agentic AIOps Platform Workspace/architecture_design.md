The repository is a product-oriented monorepo. Each capability lives in `products/<name>/` as an independently versioned Python package (uv-managed via `pyproject.toml`/`uv.lock`) with its own `src/<package>/`, `tests/`, `Dockerfile`, and `Makefile`. The root `Makefile` aggregates cross-cutting concerns: it declares `PYTHON_PRODUCTS` and `IMAGE_PRODUCTS` lists, builds coordinated container images tagged from the single `VERSION` file, renders Kustomize overlays under `shared/platform-ops/gitops/`, syncs the canonical policy bundle (`shared/shared-contracts/policies/policy-default.yaml`) into consumers, and runs the `verify` gate (tests + overlay rendering + policy validation + scenario checks + version/vocabulary lockstep). Shared assets live in `shared/`: `shared-contracts` (API/event/policy schemas and validation scripts), `shared-sdk` (client/auth/tracing helpers), and `platform-ops` (Kubernetes overlays, runtime profiles, and deploy/sync scripts). Documentation is split across `docs/specs/` (spec-driven development artifacts per release slice), `docs/adr/` (architecture decision records), `docs/guides/` (operator/user guides), and `docs/agentic-aiops-platform/` (design docs and release notes). Tutorial samples are isolated under `samples/acme-admin/` and installed out-of-band via `make deploy-samples` so they never enter the base overlay. The `policy-center` product currently holds only documentation while policy evaluation is enforced by `platform-gateway` and `tool-gateway` against the shared policy bundle.
