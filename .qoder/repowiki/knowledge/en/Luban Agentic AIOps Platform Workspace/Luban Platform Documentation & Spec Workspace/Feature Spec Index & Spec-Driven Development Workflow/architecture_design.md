This module is a documentation-only index, not code. It defines the Spec-Driven Development workflow enforced by `docs/specs/README.md` and provides one directory per feature spec under `docs/specs/SPEC-NNN-<slug>/`, each containing three files: `spec.md` (requirements + acceptance criteria), `plan.md` (technical approach), and `tasks.md` (execution checklist). A shared template set lives in `docs/specs/templates/`. Specs follow a strict lifecycle (`draft` → `approved` → `in-progress` → `delivered` → `superseded`) and are numbered sequentially; the README's spec index table is the canonical registry linking every ID to its title and status. Dependencies between specs are expressed inline via `extends SPEC-XXX` annotations rather than a build manifest, and delivery gates tie back to root-level `make verify` plus contract tests against `shared/shared-contracts`. The scope contains no executable artifacts — it is the authoritative decision record for the workspace.
