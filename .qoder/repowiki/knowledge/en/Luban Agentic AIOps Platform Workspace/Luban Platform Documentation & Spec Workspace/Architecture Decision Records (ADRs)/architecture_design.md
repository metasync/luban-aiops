Flat collection of Markdown ADRs under `docs/adr/`, each following the shared `template.md` with sections Status / Context / Decision / Alternatives Considered / Consequences. The index in `README.md` tracks every record by `ADR-NNNN` ID, title, and status (`proposed`, `accepted`, or `superseded by ADR-NNNN`). Decisions span cross-product boundaries — runtime kernel selection (AgentScope 2.0), platform-gateway extraction, broker-mediated token delegation, signed execution envelopes, durable single-use claims, OTel push metrics, per-user outbound OAuth, bounded read-only multi-agent orchestration, and spec-driven development traceability — and are referenced from specs via their status header rather than copied inline. Supersession is one-directional: newer ADRs link back to the older record while keeping it immutable.
