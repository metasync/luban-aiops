The Getting Started guide prescribes the canonical workflow: `make sync` → `shared/platform-ops/gitops/select-runtime-profile.sh default` → copy/sync `runtime-secrets.env` → `make build` (optionally `AUTO_LOAD_KIND=true`) → `make deploy` → verify via `kubectl -n dev-luban-aiops get pods,svc`; raw `kubectl apply -k` is explicitly discouraged because it resets image tags to the `dev-local` placeholder.
