Flat collection of Markdown guides under `docs/guides/` with a top-level `README.md` that indexes every guide and provides a Quick Start sequence. Guides are organized by concern rather than sub-package: onboarding (`getting-started.md`, `portal-user-guide.md`, `studio-guide.md`), data model (`documents-digest-reference.md`), identity (`user-and-role-administration.md`), runtime config (`configuration-reference.md`, `tool-configuration.md`, `luban-llm-guide.md`), governance (`approval-and-hitl.md`, `incident-guide.md`), integration (`servicenow-integration.md`, `adding-a-tool.md`, `skills-guide.md`), operations (`observability-dashboards.md`, `execution-cutover-restore.md`, `troubleshooting.md`), and reference (`architecture-overview.md`). The module is pure documentation — no code, build artifacts, or runtime dependencies — and cross-references sibling doc trees (`../agentic-aiops-platform/`, `../specs/`) plus shared ops scripts under `shared/platform-ops/gitops/`.
