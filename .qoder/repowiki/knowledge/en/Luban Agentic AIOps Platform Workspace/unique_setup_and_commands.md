Root workflow: `make sync` to bootstrap every Python product, `make verify` as the pre-commit/pre-push gate (product tests, kustomize render, dashboard validation, policy/schema/version/password-policy checks, portal build, contract & delegated-custody/runtime/multiproc/edge tests, execution-failure proof). `make build` produces coordinated images tagged `<semver>-<prefix>[-<profile>]-<sha>` and writes `shared/platform-ops/gitops/dev-k8s/.images.env`; `make deploy` applies the dev-k8s overlay. `make e2e` runs the demo suite against a running cluster with port-forwards. Policy bundles are synchronized from `shared/shared-contracts/policies/policy-default.yaml` via `make sync-policy` before consumers read them.
