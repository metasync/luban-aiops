`make verify` is the pre-commit/pre-push gate running all product tests, Kustomize overlay rendering, policy/schema validation, version lockstep checks, and secret-vocabulary validation. `make build` produces coordinated images tagged `<semver>-<prefix>[-<profile>]-<gitsha>` (dirty builds append timestamp), writes image names to `shared/platform-ops/gitops/dev-k8s/.images.env`, and can auto-load into a kind cluster when `AUTO_LOAD_KIND=true`. `make deploy` invokes `shared/platform-ops/gitops/dev-k8s/deploy.sh`; `make e2e` runs demo scripts against a deployed cluster after port-forwarding `platform-gateway:18083` and `identity-service:18081`. Policy changes go through `make sync-policy` then `make validate-policy` / `make validate-policy-scenarios` / `make policy-diff CANDIDATE=...`.
