`make verify` is the pre-commit/pre-push gate and runs every product test suite, Kustomize overlay rendering, policy scenario validation, version lockstep checks, secret-vocabulary validation, password-policy validation, and a local secret-delivery demo. `make build` produces coordinated images tagged `<semver>-dev-k8s[-profile]-<sha>` and writes `IMAGE_TAG` plus per-service image names into `shared/platform-ops/gitops/dev-k8s/.images.env`, which `make deploy` consumes to apply the dev overlay. `make e2e` runs the scripted demos in `shared/platform-ops/e2e` against a running cluster after port-forwarding `platform-gateway` and `identity-service`. Samples are installed out-of-band via `make deploy-samples` so the base overlay never references them (per SPEC-050 R-11).
