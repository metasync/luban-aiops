`make verify` is the pre-commit/pre-push gate and runs every product's test suite plus Kustomize overlay rendering, policy validation, scenario evaluation, and version lockstep checks. `make build` builds all product images with a coordinated tag derived from `VERSION` and writes image state to `shared/platform-ops/gitops/dev-k8s/.images.env`; `make deploy` invokes the dev-k8s deploy script. Policy synchronization uses `make sync-policy` to copy the canonical bundle from `shared/shared-contracts/policies/policy-default.yaml` into each consumer. Samples are installed out-of-band via `make deploy-samples` so they never enter the base overlay.
