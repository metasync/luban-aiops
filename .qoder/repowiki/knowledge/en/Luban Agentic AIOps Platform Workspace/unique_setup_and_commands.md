`make verify` runs all product test suites, renders every Kustomize overlay, and validates the canonical policy bundle — this is the enforced pre-commit/pre-push gate. `make build` coordinates image builds across all IMAGE_PRODUCTS, writes a shared `.images.env` state file consumed by `make deploy`, and can auto-load images into a kind cluster when `AUTO_LOAD_KIND=true` and `KIND_CLUSTER_NAME` is set. Policy changes must be propagated via `make sync-policy` to copy `shared/shared-contracts/policies/policy-default.yaml` into both gateway products and the deployed `policy.yaml`.
