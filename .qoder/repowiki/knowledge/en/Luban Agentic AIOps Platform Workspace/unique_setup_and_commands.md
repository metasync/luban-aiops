`make verify` is the pre-commit/pre-push gate running every product's test suite, rendering all Kustomize overlays, validating the canonical policy, and enforcing version lockstep. `make build` builds all product images with a coordinated tag written to `shared/platform-ops/gitops/dev-k8s/.images.env`, optionally loading them into a kind cluster when `AUTO_LOAD_KIND=true`. `make deploy` applies the dev-k8s overlay via `shared/platform-ops/gitops/dev-k8s/deploy.sh`. `make e2e` runs scripted demos (`skills-demo.sh`, `incident-demo.sh`, `mutating-demo.sh`) against a deployed cluster after port-forwarding `platform-gateway:18083` and `identity-service:18081`. Policy synchronization uses `make sync-policy` to copy `shared/shared-contracts/policies/policy-default.yaml` into each consumer's `policies/` directory.
