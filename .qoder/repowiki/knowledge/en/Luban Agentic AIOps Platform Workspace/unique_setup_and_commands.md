Use the root `Makefile` as the single entry point: `make verify` runs every product's test suite, renders all Kustomize overlays, validates the canonical policy bundle, and checks version lockstep; `make build` builds all product images with a coordinated tag derived from `VERSION` plus git SHA and writes `.images.env`; `make deploy` invokes `shared/platform-ops/gitops/dev-k8s/deploy.sh` to apply the dev overlay; `make sync-policy` copies the canonical `policy-default.yaml` into all consumer locations; `make validate-version` enforces that every product's declared version matches the root `VERSION` file.
