All development flows go through the root `Makefile`: `make verify` runs every product's tests, renders all Kustomize overlays, validates policy bundles/scenarios, enforces version lockstep, and validates secret vocabulary; `make build` builds all images with a coordinated tag written to `shared/platform-ops/gitops/dev-k8s/.images.env`; `make deploy` invokes `shared/platform-ops/gitops/dev-k8s/deploy.sh`; `make e2e` runs the demo scripts against a deployed cluster after port-forwarding `platform-gateway:18083` and `identity-service:18081`; samples are installed separately via `make deploy-samples` so they never enter the base overlay.
