Development uses the root Makefile as the single entry point: `make sync` installs per-product dependencies, `make test` runs all product pytest suites, `make verify` is the pre-commit/pre-push gate combining tests, Kustomize overlay rendering, policy/schema validation, version lockstep checks, and secret vocabulary validation; `make build` produces coordinated images tagged `<semver>-<profile>-<gitsha>` and writes `.images.env`; `make deploy` invokes `shared/platform-ops/gitops/dev-k8s/deploy.sh`; `make e2e` runs demo scripts against a deployed cluster after port-forwarding `platform-gateway:18083` and `identity-service:18081`. Policy changes require editing only `shared/shared-contracts/policies/policy-default.yaml` and running `make sync-policy` to propagate to gateway copies and the dev ConfigMap source.
