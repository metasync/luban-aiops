`make` targets drive the project (see `Makefile`); tests run under `pytest` against the `tests/` suite; the package entrypoint is `incident-service = incident_service.main:run` so `python -m uvicorn` or the installed CLI starts the service. Runtime behavior is controlled entirely through `INCIDENT_*` environment variables (e.g. `INCIDENT_STORE_BACKEND=postgres|memory`, `INCIDENT_DB_URL`, `INCIDENT_CONNECTORS`, `INCIDENT_QUERY_CLIENTS`, `INCIDENT_WORKLOAD_CLIENTS`).
