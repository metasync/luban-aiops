Process starts via `tool_gateway.main.run()`, which reads `GATEWAY_HOST` / `GATEWAY_PORT` (with Kubernetes `tcp://IP:PORT` port coercion) and launches uvicorn. Feature gates such as `GATEWAY_DELEGATED_ACQUISITION_ENABLED`, `GATEWAY_DELEGATED_AUTHORIZATION_ENABLED`, and `GATEWAY_DELEGATED_INVOKE_ENABLED` must be fully provisioned at startup or the gateway aborts; when disabled, routes stay registered but return 403.
