The package is layered around a single FastAPI application (`src/tool_gateway/app.py`) wired by `core.runtime.GatewayRunSettings` and exposed through the `tool-gateway` CLI entry point in `main.py`. Cross-child wiring follows one contract: `api_routes_schemas` registers routes that call into `delegated_custody_services`, which owns the SPEC-070 authorization/custody state machine (Postgres-backed) and invokes tool implementations registered in `tools_connectors_registry` via `BaseTool`/`ToolRegistry`. Provider surfaces enter through `ingestion_adapters` (MCP/ServiceNow adapters) and are surfaced as tools on the same registry. Policy decisions flow from `policies` YAML bundles through `policy_engine` into the authorization service. Observability (OpenTelemetry, Prometheus, audit events) is installed centrally in `core_runtime` so every child path emits metrics/traces uniformly.
