- Every database write opens a fresh connection via the injectable `connection_factory` and wraps mutations in an explicit `conn.transaction()` block, never holding long-lived transactions across the gateway exchange.
- Schema state is validated on every operation by calling `verify_schema(conn)`, which asserts `schema_version`, replays the table/constraint/trigger/function fingerprint, and checks `fsync`/`full_page_writes`/`synchronous_commit` are `on`.
- Errors surface as `ProtocolError(reason_code)` with a small fixed vocabulary of reason codes (e.g. `identity_conflict`, `admission_disabled`, `epoch_mismatch`, `store_unavailable`, `integrity_conflict`) rather than raising domain exceptions.
- Immutable evidence rows are enforced declaratively: the `execution_immutable` trigger blocks all UPDATE/DELETE except when the `luban.execution_retention='on'` session variable is set and the intent's expiry horizon has passed.
- Monotonicity of mutable counters/state is enforced by per-table triggers (`execution_run_monotonic`, `execution_observation_monotonic`) that reject any decrease or unexpected field change.
- Reserved observation slots (`claim`, `result`, `timeout`, `stop`, `acceptance`, `conflict`) are mapped in a module-level `_RESERVED` dict and enforced via a `UNIQUE(execution_id, reserved_slot)` constraint, giving each fact kind at most one canonical position per execution.
