Run the migrator as a standalone script: `python -m execution_runtime.services.execution_migration --epoch <uuid>` (reads `EXECUTION_STATE_DB_URL`); it refuses to auto-enable admission and exits non-zero if the store is unavailable or schema fingerprint mismatches. Runtime connections are hardened with `statement_timeout=2000`, `lock_timeout=2000`, `synchronous_commit=on`, and `idle_in_transaction_session_timeout=5000`.
