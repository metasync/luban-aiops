Thin HTTP boundary over the execution protocol services. `router.py` is the single mount point that aggregates two FastAPI sub-routers under one `APIRouter`: `health.py` (GET `/health/live`, GET `/health/ready`) and `handoff.py` (POST `/api/v1/executions/handoff`). The handoff handler authenticates callers via a shared Bearer token (`settings.handoff_token`), validates the signed request envelope with `execution_protocol.validate_request`, optionally verifies delegated identity through `delegated_execution.verify_handoff`, then drives the state machine via `ledger.claim` → `ledger.open_send` → `executor.execute_tool` → `ledger.finish`. Durability and dispatch are separated: `persist()` retries metadata writes within a bounded database budget using `database_budget`/`owned_thread`, while `stop()` falls back from an in-flight connection to `ledger.stop` when the commit outcome is ambiguous. Audit emission is fire-and-forget and never affects execution authority. Health readiness checks depend on `request.app.state.ledger.health()`, the configured signing key, handoff token, gateway URL, admission epoch, and the draining flag — making this module purely a transport layer with no business logic of its own.
