Flat collection of one-file-per-feature pytest modules under `products/agent-platform/tests/`, each named `test_<module>.py` and importing directly from `agent_service.*` production packages. Tests are partitioned by subsystem: API surface (`test_app.py`, `test_entrypoints.py`), runtime kernel and AgentScope event normalization (`test_runtime_kernel.py`, `test_chat_stream_modality.py`), session backends (`test_postgres_session_store.py`, `test_redis_session_store.py`, `test_agent_state_store.py`), execution lifecycle (`test_execution_*`), secrets vocabulary/delivery (`test_secret_*`), skills authoring/graduation/composition (`test_skill_*`), model catalog/discovery/switching, HITL approvals and flow approvals, documents/prose/redaction, and telemetry/observability. External dependencies are never hit live: Postgres is driven through a hand-rolled fake sync psycopg driver returning captured `(sql, params)` tuples; Redis uses `fakeredis.FakeRedis`; FastAPI endpoints are exercised via `fastapi.testclient.TestClient`. Shared mutable state (authoring trace store, execution record store, flow approvals registry, confirmation registry) is reset per test via `@pytest.fixture(autouse=True)` fixtures that clear module-level singletons before each test.
