Three sibling services under `agent_service.services`, each owning one artifact pipeline with no cross-imports between them:

- `skill_draft.py` (SPEC-044/SPEC-045) — two anchors (`session`, `incident`) build a digest-only bundle via `shift_summary.build_digest` plus the incident client; a bounded LLM call (`SKILL_DRAFT_TIMEOUT_SECONDS=30`) is wrapped in fail-soft logic that degrades to a deterministic facts-only skeleton. Output goes through a fenced-contract parser (````skill-frontmatter``` JSON + Markdown body), Pydantic `SkillFrontmatter` validation, shared redaction vocabulary (`REDACTION_VALUE_PATTERNS`), and UTF-8 truncation to `MAX_BODY_BYTES`. Nothing is persisted.
- `skill_graduation.py` (SPEC-055) — separates safety from rendering: `revalidate_blast_radius` re-applies replay-time guards (step budget, target/origin allowlist, write-class declaration, credential-hole scan, secret-literal shape scan against the same `REDACTION_VALUE_PATTERNS`) and returns a `BlastRadius` dataclass; only after it passes does `build_executable_flow_draft` deterministically render the trace into an executable-flow skill draft. No model call, no persistence.
- `operation_documents.py` (SPEC-039) — typed document repository with a `OperationDocumentStore` Protocol, two implementations (`InMemoryOperationDocumentStore`, `PostgresOperationDocumentStore` sharing DDL/migrations), owner-scoped visibility (`draft` vs `published`), per-owner cap (`PER_OWNER_CAP=20`) and retention sweep (`RETENTION_DAYS=30`), selected by `AGENT_STATE_STORE_BACKEND` / `AGENT_STATE_DB_URL` in `build_operation_document_store()` which exposes a module-level singleton `OPERATION_DOCUMENT_STORE` for v2 routes.

Dependency direction is one-way: `skill_graduation` imports shared constants/utilities from `skill_draft` (`postprocess`, `provenance_block`, `slug_from_title`, `REDACTION_VALUE_PATTERNS`, `MAX_BODY_BYTES`) so both draft producers share the redaction vocabulary and Skill Format caps; neither imports the other's generation path. Both depend on `execution_recovery` for evidence labels but not vice versa.
