- Closed reason codes are declared in module-level frozensets/dicts (`_PRE_DISPATCH`, `_UNCERTAIN`, `_STOP_REASONS`, `_RESERVED`) and looked up rather than compared inline, so new reasons propagate through classification and projection consistently.
- All external inputs (envelopes, arguments, attempt_request_id, timeouts, cursors, page_size) are validated before use and mapped to `ProtocolError` codes instead of raising Python exceptions, giving callers a uniform failure taxonomy.
- Database access goes through a `@contextmanager` connection wrapper that catches `psycopg.Error` and re-raises as `ProtocolError("store_unavailable")`, ensuring storage outages surface uniformly rather than leaking driver errors.
- Writes acquire per-run serialisation via `pg_try_advisory_lock` keyed by `hashlib.sha256(run_id)[:8]` before mutating state, and reads open transactions with `SET TRANSACTION ISOLATION LEVEL REPEATABLE READ, READ ONLY` plus `clock_timestamp()` for deterministic projections.
- Secrets (worker handoff token, delegated token, requester bearer) are read from `RuntimeSettings` via `getattr(..., None)` and checked before any network I/O; they are never logged or placed in stack traces.
- Owner-scoped pagination exposes a MAC-bound cursor (`_encode_cursor`/`_decode_cursor`) where the HMAC keyset includes the scope tuple (e.g. `("executions", session_id, owner_user_id)`) so a cursor cannot be replayed under another owner.
