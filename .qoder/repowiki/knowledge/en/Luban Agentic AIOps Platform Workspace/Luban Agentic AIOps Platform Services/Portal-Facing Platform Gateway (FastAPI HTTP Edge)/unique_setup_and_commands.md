Build/run via the project's Makefile fragments: `make -C products/platform-gateway help` lists targets, `make build` / `make test` / `make image` delegate to `../../mk/python.mk` and `../../mk/image.mk`. The entrypoint is the `platform-gateway` console script defined in `pyproject.toml`. Runtime behavior is controlled entirely through `PLATFORM_GATEWAY_*` and `AGENT_SERVICE_URL`/`IDENTITY_*`/`CHAT_RESPONSE_TIMEOUT_SECONDS` environment variables (see `core/config.py`).
