The package is layered around a single FastAPI application assembled in `app.py`:
- Entry point: `main.py` loads `GatewayRunSettings` from env and starts uvicorn; `pyproject.toml` exposes the `platform-gateway` CLI script.
- App bootstrap (`app.py`) installs an HTTP middleware that redacts secret-edge paths, injects request IDs, applies `no-store` headers on the authorization flow, wires Prometheus metrics and OpenTelemetry, and includes the central router.
- Routing layer: `api/router.py` aggregates one subpackage per concern under `api/routes/` (auth, authorizations, sessions, chat, documents, incidents, policy, tools, skills, models, approvals, audit, identity, runtime, health).
- Business logic lives in `services/`: `gateway_service.py` is the main proxy orchestrator (identity resolution, policy enforcement, session/chat/document/incident skill proxies), while specialized clients isolate each downstream dependency (`agent_client`, `delegation_client`, `incident_client`, `skills_hub_client`, `tool_gateway_client`).
- Policy subsystem: `services/policy_engine.py` + `policy_matrix.py` load a YAML bundle from `policies/policy-default.yaml` and evaluate actions against roles; decisions are emitted via `audit_emitter.py`.
- Auth subsystem: `services/token_verifier.py` verifies local JWTs against JWKS; `services/target_authorization.py` implements the browser-bound, provider-independent OAuth workflow for target authorization (start/callback, workload token, cookie binding) gated by `settings.target_authorization_enabled`.
- Shared core: `core/config.py` defines the frozen `PlatformGatewaySettings` dataclass loaded from environment variables with defaults for agent/identity/tool-gateway URLs; `core/request_context.py`, `core/metrics.py`, `core/observability.py`, `core/telemetry.py`, `core/secret_http.py`, `core/runtime.py` provide cross-cutting concerns.
- Schemas: `schemas/api.py` and `schemas/authorization.py` hold Pydantic models shared between routes and services.
Dependency direction is strictly inward: routes → services → core/schemas; services never import routes. The gateway is stateless — no in-process session store — and all downstream calls go through httpx AsyncClient with explicit timeout handling.
