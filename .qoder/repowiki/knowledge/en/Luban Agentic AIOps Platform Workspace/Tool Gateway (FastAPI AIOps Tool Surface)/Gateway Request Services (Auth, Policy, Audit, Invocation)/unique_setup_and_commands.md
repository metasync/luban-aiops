Policy bundle loading is controlled by `GATEWAY_POLICY_PATH`: when set, the file must exist or startup fails with `PolicyLoadError`; when unset, the packaged `tool_gateway.policies.policy-default.yaml` is used. The audit emitter is a no-op unless `GATEWAY_AUDIT_SERVICE_URL` is configured, preserving historical log-only behavior. Module-level state in `policy_engine` and `token_verifier` can be reset via `reset_policy_state()` / `reset_verifier_state()` for tests.
