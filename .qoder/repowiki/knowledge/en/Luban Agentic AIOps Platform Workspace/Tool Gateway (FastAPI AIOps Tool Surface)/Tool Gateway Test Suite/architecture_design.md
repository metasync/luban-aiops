Flat test package under `products/tool-gateway/tests/` organized by feature area: endpoint-level tests (`test_tool_invoke.py`, `test_route_inventory.py`) exercise the real FastAPI app via `fastapi.testclient.TestClient` with a live `create_app()` instance; policy tests (`test_policy_engine.py`, `test_policy_scenarios.py`, `test_policy_diff.py`) drive the `policy_engine.evaluate` API against YAML bundles loaded from `shared/shared-contracts/policies/policy-default.yaml`; connector tests (`test_browser_connector.py`, `test_elastic_connector.py`, `test_incidents_connector.py`, `test_k8s_connector.py`, `test_skills_connector.py`) mock external clients to validate I/O paths; infrastructure tests cover audit emission, redaction, telemetry, runtime settings, and registry behavior. A dedicated `test_module_parity.py` enforces byte-identity or normalized identity of deliberately duplicated modules across eight sibling products (telemetry, observability, token_verifier, audit_emitter, ingest/query auth) by reading source files from `products/*/src/<package>/...` and comparing AST-normalized text. Tests depend on the production `tool_gateway.*` packages but never import them in a way that requires network access — all external dependencies are patched via `unittest.mock.patch` (e.g., JWKS client, connector constructors).
