Mutating tools are disabled by default: `ToolRegistry.__init__` defaults `allow_mutating=False`, so `k8s.delete_pod` and all `web.*` write-tier tools are silently skipped unless the gateway starts the registry with `allow_mutating=True` (tied to the `GATEWAY_MUTATING_TOOLS_ENABLED` flag). Each connector is opt-in — Elastic requires a configured URL, K8s needs in-cluster or kubeconfig, incidents require `GATEWAY_INCIDENTS_SERVICE_URL`, and the browser connector needs a CDP endpoint plus an origin allowlist.
