Build the shared base image via `make base-images` (which forwards `BASE_UV_UV_VERSION` and `BASE_UV_PYTHON_VERSION` as `--build-arg`); override any default via `make <target> VAR=value` since all defaults use `?=`. Product images are built with `make build` (local tag) or `make push REGISTRY=<host>` to re-tag and push to a registry; `make lint` runs hadolint if available, otherwise falls back to `docker run hadolint/hadolint`.
