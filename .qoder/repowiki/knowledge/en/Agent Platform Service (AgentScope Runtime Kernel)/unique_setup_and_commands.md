Each product directory is independently built with its own `pyproject.toml` + `uv.lock` and `.python-version`; container images are built via per-product `Dockerfile`s and orchestrated through shared Makefiles under `mk/` (`image.mk`, `python.mk`). Deployment uses Kustomize overlays under `shared/platform-ops/gitops/dev-k8s/` with runtime profiles (`dashscope`, `deepseek`, `openai`) selectable via `select-runtime-profile.sh` and secrets synced by `sync-runtime-secret.sh` / `sync-delegation-secrets.sh`.
