This module is a documentation-only leaf under `docs/specs/`, grouping three sequential R5 slices that build on one another:
- SPEC-021 introduces the first bounded mutating tool (`k8s.delete_pod`) gated by a new `tools:mutate` policy action and the `GATEWAY_MUTATING_TOOLS_ENABLED` feature flag, establishing the deny-by-default risk-tier admission model at the tool-gateway.
- SPEC-054 makes action-level HITL approval first-class by adding an explicit `approval_kind` discriminator (`flow` | `action`) on the confirmation frame and durable record, replacing the accidental staleness backstop of `BROWSER_FLOW_NOT_BOUND` with kernel-side flow-context clearing plus signed authority provenance (ADR-0010), and turning every action card into a secret-masked change-request projection.
- SPEC-057 adds a third skill class `composition` — an ordered list of single-target sub-skills carrying no authority of its own, so each sub-skill retains its existing gate via `FlowContext.identity()` without new enforcement machinery.
Each spec follows the same internal layout (`plan.md` / `spec.md` / `tasks.md`) and is cross-referenced via the lineage field in `spec.md`, forming a clear dependency chain: 021 → 054 → 057, with 054 extending ADR-0007/0010 and 057 extending ADR-0011 while reusing the trust model established by 054.
