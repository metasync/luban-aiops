Three independent SPEC documents under `docs/specs/`, each following the repo's plan/spec/tasks triple: SPEC-012 defines operator-facing guides (getting-started, configuration reference, troubleshooting, tool/connector guide, architecture overview) to bridge developer specs and Kubernetes runbooks; SPEC-019 adds portal transparency — a sectioned sidebar (Chat / Control / Workspace), a live `GET /api/v1/policy/matrix` endpoint in platform-gateway backed by `policy-default.yaml`, and read-only Tools/Skills inventory proxies; SPEC-023 rebuilds the portal from vanilla JS into React + Ant Design X + TypeScript built by Vite, introducing a single platform-owned SSE contract adapter that translates stream schema v6 frames into typed models while preserving all existing backend contracts, policy actions, and audit behavior. Dependency direction is one-way: these specs describe changes to `products/operator-portal/web-ui`, `products/platform-gateway`, and `docs/guides`; they consume but do not own shared-contracts or agent runtime code.
