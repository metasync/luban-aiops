Each spec directory ships its own `plan.md`, `spec.md`, and `tasks.md` used as the single source of truth for acceptance criteria; delivery is verified by running `make build` + `make verify` against the dev-k8s overlay and live walkthroughs on `dev-k8s-transitional`, with backend selection controlled by `SESSION_STORE_BACKEND=memory|redis|postgres` and Postgres DSN via `SESSION_DB_URL`.
