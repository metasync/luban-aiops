This module is a documentation-only leaf under `docs/specs/` containing three independent but interdependent specification artifacts:

- `SPEC-049-browser-web-check-tools/spec.md` defines a stateful Playwright-based `BrowserConnector` inside tool-gateway, driven over CDP by a chromium-headless-shell sidecar. It registers a fixed `web.*` tool surface (`navigate`, `snapshot`, `screenshot`, `click`, `type`, `fill_credential`) behind an off-by-default flag, enforces a server-side origin allowlist, binds interaction tools to a skill-declared flow with one HITL gate per mutating flow, and reuses the existing `BaseTool`/`ToolRegistry`/`ToolResult` contract plus `tools:invoke` / `tools:mutate` policy actions — no new policy action or audit event type.
- `SPEC-058-http-service-check-tools/spec.md` adds two tools, `http.get` (read) and `http.post` (write), sharing the same origin allowlist, redirect-halt, scheme/userinfo/loopback destination refusals, named credential-set resolution via `CredentialSetStore`, and response projection. `http.post` parks a per-action change-request card through the existing non-browser write path in `runtime_kernel.py`, with a curated `_cr_http_post` formatter for legibility. URL secret masking is extracted from `browser_connector.py` into a shared `url_redaction.py` helper consumed by both connectors.
- `SPEC-059-acme-admin-sample-app-and-skill-suite/spec.md` ships a FastAPI `acme-admin` service under `samples/acme-admin/` with an in-memory store, machine and human surfaces, and four single-target skills demonstrating a 0/0/1/1 approval ladder (two read-only, two mutating across HTTP and browser). The app is stand-alone, built via `make deploy-sample-app`, deployed out-of-band, and kept out of `IMAGE_PRODUCTS` so the dependency direction stays tutorial → platform.

Dependency direction: SPEC-059 depends on SPEC-058 (two skills need `http.*`); SPEC-058 reuses security postures established by SPEC-049; all three preserve the existing policy/audit contracts. Each spec follows the repository's standard triad of `spec.md` + `plan.md` + `tasks.md`.
